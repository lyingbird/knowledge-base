# 平台游戏设计史

> 跳跃是电子游戏最原始的动词，也是最早被做透的动词。三个作品在十年内完成了这个类型的定义分工：马里奥定节奏，银河战士定探索，恶魔城定武器。

## 一句话概括分工

necromanov 用了一个科举式的比喻：1986 年平台游戏才能「一石」，超级马里奥独得八斗，银河战士一斗，天下共分一斗。

这个分配说的不是品质高低，是类别的分工：

| 作品 | 定义了哪个维度 |
| --- | --- |
| 超级马里奥 | 关卡节奏与跳跃精度的关系 |
| 银河战士 | 能力解锁与地图探索的闭环 |
| 恶魔城 | 2D 动作的冷兵器手感和射程控制 |

三者在 1986 到 1997 这十一年里分别立住了自己的维度，后来的平台游戏基本都是在这三条线上做变体。

## 马里奥线：把一个动词做到极致

马里奥的贡献不是「跳跃」这个动作，而是**跳跃的可控性梯度**：短按小跳、长按高跳、跑动中跳得更远、踩踏敌人获得反弹。同一个动词被拆成一组连续可控的参数。

它的关卡设计方法后来被总结成「任天堂式关卡设计」——详见 [[任天堂式关卡设计]]。核心是每次只引入一个新概念，展示、混合、加压、然后换下一个。

## 银河战士线：探索闭环

银河战士给的是另一套东西：地图是封闭的，但能力是可增长的。你看到一个够不到的平台，记住它；后来拿到高跳，回来。

这个「看到 → 做不到 → 记住 → 回来」的循环是探索型平台游戏的骨架。它的关键设计约束是**玩家必须能记住**，所以地图要有可辨识的区域特征，而不是一堆相似的走廊。

## 恶魔城线：冷兵器的正确设计

初代恶魔城（1986）在操作上是粗糙的：跳跃僵硬、定长定高、受创后会向后跃起。但它做对了一件影响深远的事——长鞭。

长鞭预示了 2D 动作里冷兵器的正确设计方向：射程控制、出手速度、走位闪躲三者构成一个完整的战斗循环。这个方向一直延续到黑暗之魂——近战的核心从来不是伤害数值，是距离和时机。

这个案例的一般性启示：**一个类型的技术缺陷会被另一处的核心洞察抵消**。初代的跳跃手感至今被诟病，但没有人否认它定义了鞭子。

## 恶魔城 3 代：1989 年就做对的分支难度

《恶魔城传说》（3 代）的设计值得单独记：三个可选伙伴（阿鲁卡多、塞法、格兰特）分别对应玩家在平台游戏里会遇到的三种困难元素，且分支路线变相降低了难度。

具体机制是：不同伙伴的能力覆盖不同类型的障碍，玩家选谁就相当于选择了自己擅长的挑战方式。这是**用角色选择表达难度选择**，而不是弹一个难度菜单。

necromanov 判断这个 1989 年的设计至今不过时。这个评价很准确——今天的许多游戏仍在用「选职业等于选难度」的思路，但没有做得比它更干净。

## 超级恶魔城 4：能力增强替代难度下调

第 4 代加了八方向长鞭和空中微调，路线仍是单线，但因为玩家能力增强，难度感变得「舒适」。

necromanov 的类比很精准：像黑暗之魂 3 对比恶魔之魂。同样的敌人强度，因为玩家手感更好、工具更多，体验从压迫变成流畅。

这是一条重要判断：**降低难度不一定要削敌人，增强玩家的操控精度效果相同，而且不损伤「我很强」的感受**。

## 后来的分岔

平台游戏在后来的演化里分成了几支，其中最重要的一支是 Metroidvania——见 [[Metroidvania类型]]。它把银河战士的骨架和恶魔城的血肉合在一起，成为独立游戏时代最繁荣的类型之一。

另一支是 3D 化，见 [[动作游戏3D化]]。

## 可执行的检查清单

- 核心动词是什么？有没有被拆成连续可控的参数？
- 能力增长与地图结构是否形成闭环？玩家能不能记住「那里我去不了」。
- 近战手感是否考虑了射程、出手速度、走位三个维度？
- 难度选择是否可以用角色或能力表达，而不是弹菜单？
- 新概念的引入节奏是否遵循「展示→混合→加压」？

## 具体案例

### 超级马里奥：跳跃的参数化

短按、长按、跑跳、踩敌反弹。一个动词拆成一组梯度，是整个类型的技术基础。

### 银河战士：能力解锁闭环

看到够不到的地方、记住、拿到能力后回来。探索型平台游戏的骨架，约束是地图必须可辨识。

### 恶魔城初代：长鞭定义冷兵器

跳跃手感粗糙，但长鞭确立了射程控制、出手速度、走位闪躲的三元结构，延续到魂系。

### 恶魔城传说：三伙伴对应三种困难

用角色选择表达难度偏好，分支路线变相降难度。1989 年的设计至今不过时。

### 超级恶魔城 4：增强而非削弱

不削敌人，而是给玩家八方向长鞭和空中微调。难度感变舒适，但「我很强」的感受保留。
