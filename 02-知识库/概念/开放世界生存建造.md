# 开放世界生存建造

> 这个品类在全球核心玩家中已经是主流，但它长期被独立团队承包，通病是门槛高、优化差、BUG 多、演出粗糙、难度残酷、数值不平衡。王国之泪做的事，本质上是把这个品类的每一项缺点换成反义词。

## 品类的画像

necromanov 用 Steam Tag 系统做了洞察，称之为全球核心 PC 玩家观点的晴雨表。

五组强相关标签：生存、开放世界、制造（Crafting）、建造（Building）、沙盒（Sandbox）。

前十名游戏没有 3A 大厂，但销量不低：

| 游戏 | 开发商 | 销量 |
| --- | --- | --- |
| Terraria | Re-Logic | 4450 万 |
| 方舟 | Wildcard | 3330 万 |
| 饥荒 | Klei | 2500 万 |

深海迷航（Unknown Worlds）也在其中。

这组数据说明一件重要的事：这是一个被独立团队验证过需求、但没有被大厂工业化的品类。需求是真的，供给是粗糙的。

## 六项通病

necromanov 列的品类缺点，值得完整记录：

- 门槛高。
- 优化差。
- BUG 多。
- 演出粗糙。
- 难度残酷。
- 数值不平衡。

这六项不是「功力不足」，是资源分配的必然结果。独立团队没有余力做优化、做演出、做数值平衡，只能把有限资源投在核心系统的自由度上。

所以这个品类的产品往往有一个共同特征：系统极深，体验极糙。玩家为了那个深度忍受一切。

## 任天堂的换词游戏

任天堂擅长把其他公司的新奇玩法变成完成度吓人的杰作。具体做法是把六项通病逐一换成反义词：

| 通病 | 王国之泪的做法 |
| --- | --- |
| 门槛高 | 自然引导 |
| 优化差 | 到位优化 |
| BUG 多 | 高完成度 |
| 演出粗糙 | 绝妙关卡进程 |
| 难度残酷 | 舒适难度 |
| 数值不平衡 | （相对改善） |

这不是创新，是补齐。necromanov 的判断很准：王国之泪不是一个新品类，是一个旧品类被补齐短板后的样子。

这套方法论的可复制性在于：它不需要发明新玩法，只需要识别一个「需求已验证但供给粗糙」的品类，然后用工业能力把粗糙补平。前提是有工业能力。

## 王国之泪为什么是这个品类

判断依据不是「能建造」，而是玩法结构的相似性：

- 究极手 + 蓝图对应建造与沙盒。
- 通天术对应开放世界的纵向移动。
- 余料建造对应制造与合成。
- 探索—收集—改造的循环对应该品类的核心节奏。

necromanov 特别指出：这些技能不可能在项目中后期临时改出，必在立项阶段决定。也就是说，任天堂在做续作时，是先选了这个品类理念，才设计了这四个能力。

这个顺序很重要。常见做法是先想能力再找品类；任天堂是先定品类，再从品类推导能力。

## 品类的边界

不是所有带建造的开放世界都属此列。判据在于建造是否是核心循环的一环：

- 如果建造是可选装饰（比如只用来盖房子），那这款游戏是开放世界 RPG，建造是附属功能。
- 如果建造是解决问题的主要手段（比如必须造载具才能过河），那它属于这个品类。

按这个判据，王国之泪属于此列——大量神庙与任务的正解是「造点什么」。

## 检查清单

- 这个品类的六项通病，这款产品修好了几项。
- 建造是核心循环的一环，还是可选装饰。
- 是先定品类再推导能力，还是先想能力再找品类。
- 系统的深度是否足以让玩家忍受粗糙，如果不能，粗糙就是致命的。
- 有无工业能力把「补齐短板」这件事做完全。

## 具体案例

### Terraria / 方舟 / 饥荒：需求的验证者

销量 4450 万 / 3330 万 / 2500 万，全部来自独立团队，前十名无 3A 大厂。这组数据证明需求真实存在，只是没人用工业能力去满足。

### 王国之泪：补齐版

四大能力全换（究极手、余料建造、通天术、逆转乾坤 + 蓝图），希卡石板换普尔亚平板。六项通病多数被补齐，代价是后期罐头化（神庙多为一段两段式，复制粘贴明显）。
