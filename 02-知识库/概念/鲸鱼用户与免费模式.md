# 鲸鱼用户与免费模式

> 免费模式的数学很简单：1-3% 的鲸鱼用户支撑其余 97% 的免费用户。但它的前提容易被忽略——付费必须「他人可见」。鲸鱼买的不是内容，是地位。

## 核心数字

necromanov 的表述：只要内容在网络上、他人可见，总有 1-3% 鲸鱼用户足以支撑其余免费/盗版用户。

这个数字在免费游戏行业里被广泛引用。它的意义是：免费模式的可行性不依赖「转化率有多高」，而依赖「头部用户愿意付多少」。

## 为什么是「可见」在起作用

这是最容易被忽略的一点。

如果付费带来的东西只有自己知道（比如单机游戏的内购装备），鲸鱼的付费动机大幅削弱。

如果付费带来的东西别人能看到（排行榜、稀有外观、稀有称号），付费就变成了地位购买。

所以免费模式的设计重心不在「卖什么」，在「怎么让买的人被看见」。

具体手法：

- 排行榜（展示排名）。
- 外观（展示品味与花费）。
- 稀有度标识（展示投入）。
- 社交场景（在他人面前使用）。

## 三个必须成立的前提

免费模式不是万能的。它成立需要：

**前提一：用户规模足够大。** 1-3% 的绝对数量要够养活产品。
**前提二：付费内容可见。** 没有可见性就没有地位购买。
**前提三：免费用户的体验不能被严重破坏。** 否则免费用户流失，鲸鱼的「观众」也没了。

第三条最关键也最容易被违反。当产品为了逼付费而恶化免费体验时，它实际上在减少鲸鱼的观众——最终鲸鱼也失去了付费动机。

## 与买断制的结构对比

| | 买断制 | 免费 + 鲸鱼 |
| --- | --- | --- |
| 收入来源 | 所有买家 | 少数鲸鱼 |
| 定价逻辑 | 内容价值 | 地位价值 |
| 用户结构 | 同质 | 分层（鲸鱼/普通/免费） |
| 设计重心 | 完整体验 | 分层体验 |
| 失败模式 | 卖不动 | 免费用户流失→鲸鱼失去观众 |

最后一行是本页最有价值的对照：两种模式的失败原因完全不同。

买断制失败是「没人愿意付钱」，免费制失败是「付费的人失去了被看见的舞台」。

## 悖论：内容可见与体验完整

necromanov 在讨论买断制加内购时提到的问题，正好是这个悖论的镜像：

买断制的契约是「一次付费，完整内容」。加内购破坏了它。

而免费制的契约是「免费可玩，付费可变强」。这个契约本身就是分层的。

所以两种模式的付费设计不能混用。混用的结果是两份契约都被违反——玩家既觉得被收了钱，又觉得体验不完整。

## 检查清单

- 用户规模是否支撑 1-3% 的绝对数量。
- 付费内容是否他人可见。
- 免费用户的体验是否被破坏。
- 免费用户流失后，鲸鱼的观众还在不在。
- 付费模式是否与内容结构匹配（买断 vs 免费）。

## 具体案例

### 1-3% 鲸鱼

少量高付费用户支撑其余免费用户。前提是付费可见。

### 免费体验恶化 → 鲸鱼失去观众

违反第三条前提的后果：免费用户流失，鲸鱼的展示场景消失，付费动机削弱。

### 买断 + 内购的契约冲突

两种模式的契约不能混用。混用导致两份契约都被违反。
