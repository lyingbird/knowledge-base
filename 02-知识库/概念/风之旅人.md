# 风之旅人

> Journey（2012）是独立游戏的神话。它的成本不在画面，在一整套前所未有的游戏设计：多人随机进出他人游戏、全程无冷场、不同类型关卡匹配、完整的元游戏概念、「不需要任何教程与文字」的坚持。这些成本，只有做过的人才知道。

## 为什么它是基准

necromanov 在批评 Abzu 时，用的基准就是风之旅人。

他的做法很值得学：要判断一部作品放弃了什么，先看它的前作付出了什么。

风之旅人付出的东西，他列了一份清单：

- 多人随机进出他人游戏。
- 全程无冷场。
- 不同类型关卡匹配。
- 完整的元游戏概念。
- 「不需要任何教程与文字」的坚持。
- 各种前所未有的游戏设计形式。

这份清单的特点是：每一项都很抽象，很难一句话说清，也很难被外行看出来。

## 隐形成本

necromanov 的判断是：这些成本和艰难，资深同行能体会。

这句话点出了一个行业现象——**创新设计的成本是隐形的**。

玩家看到的是成品：一段无对白的旅程，一个陌生人的陪伴。看不到的是：

- 多人随机匹配怎么做到「随时有人来、随时有人走」而不破坏体验。
- 无教程怎么教会玩家所有操作。
- 「全程无冷场」需要多少关卡节奏的反复调整。
- 不同类型关卡（沙地滑行、雪山攀爬、水下）如何共用同一套操作。

这些都无法从成品里反推。所以当后来者做「精神续作」时，很容易误判成本——以为照搬美术风格就够了。

## 与 Abzu 的对照

necromanov 的核心不满是：Abzu 是风之旅人「设计思路核心复制的劣化版本」。

具体来说，Abzu 保留了美术表现力，删除了所有游戏设计。

| | 风之旅人 | Abzu |
| --- | --- | --- |
| 美术 | 强 | 更强（色彩极端鲜艳） |
| 陌生人互动 | 有（核心） | 无 |
| 无文字叙事 | 有 | 有 |
| 关卡节奏 | 反复调整 | 生物群的简单递进 |
| 谜题 | 融合在探索里 | 开门 = 游到某地搬开关 |
| 元游戏概念 | 完整 | 无 |

关键差别不在最后两行，在「风险」这一项。风之旅人的每一项设计都有失败风险，Abzu 的每一项都是安全选择。

## 它证明了什么

风之旅人证明了一件事：**「不需要教程与文字」是可以做到的，但需要付出数倍的关卡设计成本**。

这个证明有两个后果：

- 好的后果：后来者知道这条路可行。
- 坏的后果：后来者可能只学表面（无文字、强美术），不学里子（关卡设计成本）。

Abzu 属于后者。这不是 Abzu 一家的现象，是整个行业对「创新成本不可见」这件事的普遍误判。
