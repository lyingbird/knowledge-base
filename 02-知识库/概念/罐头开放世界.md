# 罐头开放世界

> 「罐头」指的是 Checklist 开放世界。它仍是商业价值最高、开发难度最高的品类——当开放世界大作与线性关卡大作同档期，前者几乎碾压后者。它的问题不是 UI 太啰嗦，是体验在重复。

## 先否掉一个错误诊断

2022 年流传一张「如果育碧来做艾尔登法环」的恶搞图，把罐头的问题归到易用性与指引 UI 上。

necromanov 指出这是错的二分法。From 并非主张不做易用性——法环加了传送大地图、光柱引导、NPC 图标（1.03 补丁）、对策道具。他的判断是：易用性和指引是所有游戏都要追求的目标，绝非敌人，就算多一倍也仍出色。

真正的问题在更深处：**玩家为什么厌烦「问号/任务列表」，却不厌烦法环？**

## 成因：专业分工必然导致体验重复

答案在于现代大型开发的本质。

necromanov 的表述很直接：现代大型开发本身就是公式化工厂。核心小组决定核心玩法，各小团队复制体验。专业分工越彻底，体验越重复——育碧会细分到植被、动物、建筑、据点各有专门团队，每个小团队都在复制同样的体验。

这不是某个团队的能力问题，是组织结构的必然产物。分工会提高效率，同时也会让所有输出趋向一致。

三种传统解法，各有局限：

| 解法 | 代表 | 局限 |
| --- | --- | --- |
| 靠叙事 | 上古卷轴 5、新维加斯、巫师 3 | 叙事成本高，且只能覆盖主线周边 |
| 更长时间打磨核心玩法 | 传统做法 | 时间成本不可控 |
| 过程生成 | 看门狗 3 | 生成的内容无设计意图，很快被识破 |

三种失败样本：2077 叙事不足、看门狗 3 过程生成致重复、龙腾 3 / Rage 2 / 真三国无双 8 把开放世界当等级条。

## 第三种解法：把多样性作为开发方针

艾尔登法环走的是第三条路：直接用足够多样的独特内容填满世界，把多样性本身作为开发的核心指导方针。

necromanov 统计的内容量：300+ 武器各独特模组、40+ 专属战技、98 战灰、70 魔法、101 祷告、64 骨灰、150+ 套装、100+ 战斗道具。300 人核心团队做出比三代魂加起来还大的量。

更值得看的是分布特征：

- 每个地点都有独特回报。废墟地下室、巨人车队宝箱、宝石虫战灰、NPC 支线、逃课技巧（跳教堂墙射大树守卫），几乎每点都给新敌种 + 独特装备。
- 仅宁姆格福西区，若育碧做会标 40+ 问号——而法环的密度与质量反而更高。
- 50+ 有赐福的小型场景，几乎每个都有独特 BOSS + 独特回报 + 独特逻辑。
- 18 个大中型关卡（史东威尔城、诺克隆恩-希芙拉河、罗德尔王城-下水道等）凌驾黑魂 1 或血源整个游戏。

所以关键差别不是「有没有问号」，是问号背后是不是同一份内容。

## 四条可操作的方针

necromanov 从法环提炼的经验，逐条都有操作性：

**内容量第一优先级。** 哪怕做不好后面拿掉，也比反复修改但体验重复有价值。

**横向丰富体验而非纵向数值成长。** 视频时代要的是可传播的横向差异，不是数值阶梯。为此可以容忍不平衡。

**成功理念与审美可复用，形成挑战阶梯。** 沼泽有马 / 无马的两种版本、法师镇 / 仪典镇的两种处理，同一个母题给出不同难度与解法。

**创新执行权下放到每个制作小组。** 逃课小设计之所以到处都是，是因为每个小组都被允许在自己的关卡里做创新。

## 副作用是必付的

必须记录代价。追求多样性导致中后期直剑脱离平衡中心（BOSS 大量中远距 AOE + 针对 AI），后期隐藏关卡（下水道、化圣雪原、蒙格温）用低可见度、堆怪、复用素材，受到差评。

necromanov 的判断是：这是必付代价。容忍不平衡换取多样性，是有意识的交换，不是失控。

## 检查清单

- 这个世界里的内容，是不是由多个小团队各自复制的近似物。
- 每个地点是否有独特回报，还是同一份内容换个位置。
- 问题不在 UI 是否啰嗦，而在问号背后是什么。
- 多样性是否被当作开发方针，还是被当作美术目标。
- 有没有形成挑战阶梯（同一母题的多难度版本）。
- 创新执行权是否下放到小组，还是集中在核心组。
- 如果不平衡换来了多样性，这个交换是否被明确承认。

## 具体案例

### 艾尔登法环：300 人做出比三代魂更大的量

300 人核心团队，18 个大中型关卡各凌驾前作整体。宁姆格福西区若育碧做会标 40+ 问号且「质量更高」——这句话是关键，它说明法环的密度不是靠数量取胜，是靠独特性。

### 看门狗 3：过程生成致重复

把开放世界填充交给过程生成，玩家很快识破内容有限。这是「用算法替代设计」的失败样本。

### 龙腾 3 / Rage 2 / 真三国无双 8：把开放世界当等级条

三种不同的偷懒方式，共同点是把开放世界理解为「更大的地图 + 更高的等级」，而不是「更多样的体验」。
