# 魂系游戏设计

> 「魂式范式」是一整套可拆解的设计语法，而不是「很难」这个印象。它的战斗面是「精力-韧性-防御动作」的资源三角（血源/只狼各自抽换一角完成特化），关卡面是「篝火-捷径-单向门」的箱庭三元素（幽邃教堂是教科书案例），体验面是「死亡惩罚 + 模糊叙事 + 恶意服务成长」。类魂作品失败的形态高度一致：复制结构而不复制节奏（明末），或只学会难度而不学会公平（匹诺曹）。本页是该范式的总纲，为库内三作（[[黑神话：悟空]] / [[明末：渊虚之羽]] / [[影之刃零]]）与 [[魂系列与巫师3]] 的商业路径页提供机制层地基。

## 一、战斗面：资源三角与两次特化

### 原教旨魂：精力-韧性-防御动作

魂式战斗的底层是三个互相咬合的系统：

- **精力条**：攻击、格挡、闪避全部消耗精力，归零即大硬直——它强制玩家「输出一半、留一半」，把无脑连段从系统层面禁掉，形成被戏称为「回合制」的攻防节奏：看招、避招、找窗口、回精力。
- **韧性（Poise）**：一项**不向玩家呈现**的隐藏数值，被攻击「削韧」到 0 时敌人失衡可处决。玩家很可能通关都不知道它存在——削韧处决是锦上添花，清空血条才是根本目标。负重系统与之挂钩（超重影响翻滚与精力），支撑起「乌龟流」等 Build 多样性。
- **防御动作分层**：格挡（低风险稳定扣血）、弹反（时机成功则立即失衡可处决，失败吃全额伤害——高风险高收益）、背刺绕后（位置博弈）。三者的风险收益梯度是魂式战斗的骨架。

### 血源诅咒：抽掉防御，奖励进攻（2015）

特化方式是做减法：盾牌聊胜于无、护甲减伤边缘化、负重删除——「乌龟」打法不复存在。空出的防御位用两个机制填补：**枪反**（把弹反从接触瞬间改为射击时机，自由控制交战距离）与 **Rally 系统**（受击后短时间内主动进攻可回血，「虚血」转化）。后者的价值在设计层面最值得记：它把玩家受击后的本能（逃开喝血）重新编程为（冲上去砍回来）——**用一条规则改写玩家的应激反应，比任何数值鼓励都有效**。

### 只狼：抽掉精力，立起架势槽（2019）

只狼的激进在于直接删除精力条（攻击防御闪避不再受限），用**架势槽**从另一侧约束行动：攻防双方都有可见的架势槽，受击、格挡、攻击被格挡都会累积，满槽即破防——玩家破防挨长硬直，敌人破防（或血量清空）可「忍杀」。它与韧性机制的三点关键差异决定了体验差异：

1. **可见**：韧性藏在后台，架势槽挂在屏幕中央——玩家从「不知道自己为什么赢」变成「清楚看见破防进度」。
2. **与血量动态耦合**：血越少架势槽越长、回得越慢——两条资源互为杠杆。
3. **从锦上添花变成必经之路**：Boss 必须固定次数忍杀才能击杀，架势槽比血量更重要。

配套的收益重分配是宫崎英高最狠的一刀：普通攻击收益极低、格挡不累积敌方架势槽、**只有弹反同时「免伤 + 涨对方架势槽 + 不涨自己多少」**——弹反从选做题变成必做题，动作游戏被做成了「音游」。识破（踩突刺，判定宽松）补上另一半。代价是 Build 多样性几乎归零（一把打刀、无加点流派），这是「深度换广度」的极端交换。

### 验证案例：匹诺曹的谎言——把两套系统捏在一起的失败（2023）

匹诺曹同时保留了魂式数值（血量/负重/道具补充）与只狼式弹反主张，但把「韧性」与「架势槽」捏合成一个「白条」系统：敌人先硬直、再打白条、再蓄力攻击才可处决。失败在**循环的每一环都可能被打断**：白条出现时敌人往往仍自由行动（蓄力打不出）、处决收益低于直接补战技（玩家理性放弃处决）、弹反窗口判定与闪避性能都偏弱。游研社的结论值得存档：**机制堆料不等于机制咬合——魂式手感的来源是每个系统互为因果，而不是每个系统都存在。**

### 2023-2026 年的谱系位置

- **回归魂式数值**：匹诺曹的谎言、第一狂战士卡赞（2025）——精力/削韧/负重全套回归，卡赞甚至以「五道门槛」（精力管理/削韧处决/完美格挡/完美闪避/怒意爆发）作为新手引导框架。
- **继续只狼化**：明末的化解设限（见该页教训）、影之刃零的蓝光弹反+连段弹反（把「识别起手」的只狼范式再往前推一步：弹到第一下自动弹完整套，成就感从背谱移到识别）。
- **RPG 化分流**：法环在魂式底座上重加 Build 广度（战灰/骨灰/法术），艾尔登法环之夜（2026）则把 PVE 合作加入——范式继续向两端拉伸。

## 二、关卡面：箱庭三元素

魂式关卡的可复制成分与不可复制成分需要分开，明末与黑神话的教训各占一半。

### 三元素与心理机制

- **篝火（存档点）**：刻意稀疏——魂 1 绝大部分区域 2-3 个，前期无传送。稀疏本身不产生乐趣，它为「捷径回环」提供参照系。
- **捷径**：从篝火出发绕一个大环，尽头开门回到篝火。「发现新篝火」远不如「开路回到旧篝火」惊喜——因为后者让玩家瞬间建立区域连通关系（尤里卡时刻），且实际消除了跑图惩罚。洛斯里克高墙、幽邃教堂（全图仅净身小教会一个篝火，所有路径以它为核心）是标准案例。
- **单向门**：「不能从这一侧打开」同时承担三个功能：主线向导（暗示目的地）、支线伏笔（记下待办）、捷径本体（从另一侧打开即回环）。它是弱引导游戏里最便宜的引导设备——一句话替代了整个任务箭头系统。

### 配套系统

- **奖励驱动的探索**：魂 3 的道具布点让「看到的宝物」成为引力锚点（断桥对面、锁着的监狱），隐藏奖励满足寻宝欲，NPC 事件与结局分歧藏在支线里——反复跑图因奖励丰厚而不无聊。
- **视线引导与心流**：高墙拆解（机核）指出其心流设计是「空间服从于心流」：垂直高度重叠、所有岔路围绕篝火旋转、视线引力早早把目标种进玩家脑海。同时也暴露了经典失误：主路与捷径入口视觉优先级完全相同，叠加「多数玩家本能先走右边」的习惯，大量玩家开荒即迷路——**魂式引导不是没有引导，是把引导做进视线与光影，做错时同样致命**。
- **场景复用**：黑魂 3 压缩地图实际体积、靠多路径复用同一场景（幽邃教堂的弓箭手位置后来变成可探索道路），既减负又实现无缝连接——这是技术约束转化为设计优势的典型。

### 恶意的边界：「受苦」与「刁难」的分界线

魂式恶意（拐角藏怪、卡视角偷袭、病村）成立的前提是**恶意服务于学习循环**：玩家死得明白（「难但公平」，能说清自己为什么死）、死后有明确变强的路径（经验/道具保留、跑尸路线经捷径缩短）。超出这个边界的恶意——明末的假篝火与堆叠陷阱、魂 2 的堆怪——得到的评价会从「受苦」滑向「刁难」。这条分界线是本页最重要的判据，明末页与主题页判断二均引用它。

## 三、体验面：死亡惩罚与碎片叙事

- **死亡惩罚的真实结构**：掉魂可捡回（非清空）、死前进度保留（门/道具不重置）、无法读档逃避惩罚、消耗品在 Boss 战中打掉就真没了——压迫感来自「资源不可逆」而非「进度清零」。跑尸的痛苦与捷径的惊喜是同一枚硬币。
- **碎片化叙事**：关键信息拆到物品说明、NPC 只言片语、场景布置（石化的祈祷居民、散落的骑士装备），分层发布、拒绝CG直给。开发上它降低过场成本，设计上它制造解读空间与社区考据文化——**模糊不是没写，是精确控制的信息释放**。明末继承了这个形态（壁画/家书），但它的叙事争议说明：碎片叙事的「留白」在国产历史题材语境下会被玩家用「历史预期」填补，留白方向与预期错位时后果不受控（见明末页视听叙事节）。
- **联机与社区**：留言/幻影/入侵把「其他玩家」变成世界观的一部分（「赞美太阳」式的社区共创），这是魂式体验里最不可复制的一层——需要发行规模与玩家文化双重沉淀。

## 四、设计判据（供引用与自查）

1. **资源三角是否咬合**：精力/韧性（或其替代物）是否互相约束、是否塑造了攻防节奏？只抽掉一角时，空位用什么填补（血源=Rally，只狼=架势槽）？匹诺曹的反例：全都有但不咬合。
2. **防御动作的风险收益梯度**：弹反高风险高收益、格挡低风险低收益、闪避中风险中收益——三档是否均衡？明末反例：闪避过强+化解设限，梯度塌成单档。
3. **箱庭三元素是否闭环**：篝火-捷径-单向门是否形成回环？「开路回旧篝火」的尤里卡时刻是否存在？
4. **恶意是否服务学习**：每一次陷阱/伏击死亡，玩家能否说出「下次怎么办」？说不出的恶意就是刁难。
5. **信息释放是否精确**：碎片叙事的留白是否是设计好的？还是干脆没写？
