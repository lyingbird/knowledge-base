# 西洋动作游戏设计

> 「真实性」在动作游戏里是一个陷阱。真实的人不能一刀砍三个，真实的盾兵就是要先破盾——但把这些都做进去，得到的不是真实，是迟钝。日本人在三十年里做出的连击、防反、翻滚、爆气槽，不是花招，是把「打起来爽」这件事拆解出来的基本工程。

## 「真实性病毒」

这个概念来自 necromanov 引用的一篇访谈（4gamer 对特洛伊无双加拿大 GD 的采访，经作者意译）：西洋设计师重视真实性，因此有四个执念：

- 不能一刀砍 N 人。
- 无双不能跳 3 米。
- 每个敌人都要让玩家吃瘪。
- 盾兵做得特别硬，要先打盾。

四条单看都合理，合起来的结果是：玩家每一次出手都被系统告知「你不行」。这不是难，是钝。

## 真实性与可玩性的冲突在哪

冲突不在「真实」和「爽」之间，在**反馈的清晰度**上。

真实的战斗里，一次挥砍的结果取决于角度、力量、护甲、疲劳、运气，玩家无法从中读出因果。游戏需要的是相反的东西：每次输入都有一个确定的、可预期的、即时可见的结果。

日本动作游戏三十年积累的那套东西，本质就是在建立这种可读性：

| 机制 | 解决的问题 |
| --- | --- |
| 硬直 | 让「打中了」有明确的时间证据 |
| 判定 | 让「该不该中」有明确的空间证据 |
| 防御与闪避 | 给玩家一个可靠的应对选项 |
| 输入有效时间 | 让操作意图不被系统吞掉 |
| 连击 | 把单次操作串成有节奏的序列 |
| 爆气槽 | 给压力一个释放出口 |

这六项没有一项是「花招」，每一项都是把玩家的意图翻译成系统语言的基础设施。

## 猎魔人 2 的双重失败

necromanov 对猎魔人 2 的评价里，动作部分是重点批评对象，理由有两条，方向相反：

**第一条：难，但难错了地方。** 不是恶魔之魂那种「操作精确但严厉」的难，是「操作本身不听话」的难。作者区分得很清楚：恶魂的难要求你练，猎魔人 2 的难要求你忍。

**第二条：为了「RPG」砍动作。** 该有的动作被大量删除，挪进技能树。作者打了个比方：没了防反的防御，像没放蒜的蒜味拉面——名字还在，实质没了。

第二条更值得记，因为它是结构性的：**把动作拆成技能树上的解锁项，等于承认动作不是核心，是奖励。** 这个选择一旦做出，动作部分的水准就注定有限，因为它的预算和优先级都被降级了。

## 「维护传统」不等于「无视进步」

这句话原本是用来评价猎魔人 2 的 RPG 部分，但它对动作部分同样成立，甚至更尖锐。

猎魔人 2 的传统 RPG 部分极为用心：再普通的打怪任务都有逻辑、情报、专用诱饵陷阱；稍像样的任务有多种路线与完成方式；地下城充满细节与小演出。

但同一个游戏的细节体验停留在 1998 年：有负重却无一键售出，复杂任务无关键提示，地图材料满地却无自动拾取，怪物死后 5 秒才能拾取。

作者的立场很明确：该承认设计技术进步的就要承认。抱残守缺不是传统，是懒。

这个判断可以推广成一条判据：**判断一个设计是「传统」还是「落后」，看它保留的是体验还是麻烦。** 保留「任务需要动脑」是体验，保留「找东西要反复按键」是麻烦。

## 与日式动作的分野

两者的分野不在难度，在**难度的来源**。

日式动作（恶魂、鬼泣、猎天使魔女）的难度来自「你要做得更好」：判定清晰、操作可控、失败有明确原因。

西洋动作（猎魔人 2、Risen、Gothic 一类）的难度常来自「系统不配合」：判定模糊、输入延迟、敌人行为不可读。

前者训练玩家，后者消耗玩家。这就是 necromanov 说「先补基本功再谈真实性」的意思——基本功不是让游戏变简单，是让失败有意义。

## 检查清单

- 有没有把「真实」当成不做设计的理由。
- 硬直、判定、防御闪避、输入有效时间是否达标。
- 难度来自「你要做得更好」还是「系统不配合」。
- 动作是否被拆进技能树，等于降级为奖励。
- 保留的是体验还是麻烦。
- 敌人行为是否可读。

## 待核验点

- 4gamer 对特洛伊无双加拿大 GD 的访谈观点，是作者经懂日语友人转述的意译，非原话，引用时需注意。
- 猎魔人 2 与恶魔之魂的操作性比较为作者主观体验，无客观数据。
- 六项基础设施的表格是本文归纳，其他分类方式（如 3C 框架）是否更合适需检验。
- 「西洋动作游戏」这个类型边界模糊，是否包含英法等国的作品需界定。
