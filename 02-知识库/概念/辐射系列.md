# 辐射系列

> 一个类型演变的完整样本：从前三部曲的「小众神作」，到后三部曲的「大众产品」，再到 76 的「背叛核心用户」。这条线上每一段的成功与失败，都可以用同一把尺子量——有没有保留核心乐趣。

## 前三部曲：技术进步催生的开放世界雏形

necromanov 的分析很有历史感：辐射 1（1997）、2（1998）诞生于 2D 转 3D 的年代，建立在 1988 年文字互动 RPG《废土 1》之上。

关键的技术观察：黑岛察觉到 PC 不再受显示色数、活动块、存档、读取的限制，于是把「多样的玩法」与「自由的世界」合为一体。

销量：辐射 1 最终 60 万，辐射 2 达 70 万。这个数字开启了 CRPG 的「文艺复兴时代」——其后有博得之门、冰风谷、异域镇魂曲。

## 非线性的种子

necromanov 举了一个具体例子：辐射 2 的 Vault City 有三层进入方式。

- 暴力破城。
- 核电厂过载。
- 公民测试。
- 守卫队长。

他认为这是非线性设计的典型，预示了未来的「开放世界」。他还画了演变路径：CRPG → 非线性 → 沙盒 → 开放世界，走了 20 年。

这个观察的价值是：开放世界不是突然出现的，它是 CRPG 自由度的技术兑现。

## 后三部曲：小众玩法推向大众

B 社（Bethesda）的辐射 3、新维加斯、辐射 4 做了一件事：把「小众神作」辐射与「大众爱好」FPS 结合。

结果：系列从不到百万带到单作千万销量。辐射 4 首周 1200 万套。

necromanov 的判断很关键：后三部曲可看作前三部曲在新技术下的投影。

具体改动：

| 增加 | 去除 | 保留 |
| --- | --- | --- |
| 射击、战斗、关卡、缴获 | 缓慢探索、冗长对话 | 最受欢迎元素 |
| | | 观察指令→场景叙事 |
| | | 技能阵列→制造建造 |

这个表格的读法是：它不是「简化」，是「换载体」。把文本承载的自由度换成空间承载的自由度。

## 76：错误归因的代价

辐射 76 的失败，necromanov 用了一个经典类比：二战美军统计返航飞机弹孔。

统计学家瓦尔德指出：没统计到的是「中弹即无法返航」的引擎。

对应到辐射：如果只看本系列销量，会得出「RPG 越少、FPS 越多销量越高」的谬误。但把市场上其他 FPS/TPS（Steam 上千款，多数销量远不如辐射）和多人射击（超过 50 款逃生死局）加入图景，逻辑逆转。

**真相是：玩家因为「射击游戏里还能低门槛体验 RPG 核心乐趣」才来的。单纯比射击，辐射毫无竞争力。**

necromanov 的比喻：被击落的飞机，就是市场上那些做 FPS/多人失败的竞品。

## 76 的具体失败

- 删除人形 NPC 与深入交互，任务无剧情无分支，用机器人/磁带/触发器简化一切。
- 场景叙事从「塑造世界观」沦为「节约成本」。
- 400 人制作的内容传播量不如一个帆布包事件。
- 多人模块「没有设计」：32 人服务器丢进 200 个地点 + 20 个建设区，无资源争夺、无合作敌人，玩家孤独刷怪。
- 后端程序员仅 4 人（400 人中）。
- 建造系统充满「掉线即消失、被自动打包」的设计。

最后一条最刺眼。400 人的团队，后端只有 4 人——这说明项目在立项时的判断就已经错了。

## 这把尺子

整个系列的历史可以用一句话衡量：**核心乐趣是「在小众深度里体验自由」，不是「在主流玩法里打枪」。**

- 前三部曲：用文本与 2D 承载深度。
- 后三部曲：用空间与 3D 承载深度。
- 76：放弃深度，只留主流玩法。

前两步是换载体，第三步是换本质。
