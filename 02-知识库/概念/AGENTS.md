## 给 AI Agent

### 在此目录工作
- 命名：`{名称}.md`，用稳定短名（`AI原生公司`、`智能密度`）。
- **front-matter**：`tags` / `created` / `updated` / `sources`（列出关联素材）。
- 每页含：一句话摘要（`>` 引用）、核心定义、判断标准/要点、相关页面。
- **底部「相关页面」必填**，建立双向链接网络。
- **防近义词重复页**：建页前查 `06-手册/知识库规范.md` 别名词表（如 `AI原生公司 = AI原生组织`、`agent = 智能体`、`AI安全 = AI治理`），用别名而非新建页。
- 区分「已从素材提取的观点」和「后续推论」。
- ingest 时新概念要新建或**更新**已有实体页，不能只建摘要。

### 校验要求（Lint）
- 孤立实体（无入链/出链）。
- 概念重复（多个近义词页指向同一概念）。
- 实体页是否被至少一个 `02-知识库/素材/` 或 `02-知识库/主题/` 引用。

### 常见模式
- 实体页用 `[[实体名]]` 互相链接，形成概念网。
- 与 `[[04-历史主题/...]]` 旧页同名时，新页在 wiki 层用短名，旧页保留路径。
