# 选择与分支的区别

> 分支是「你可以走不同的路」，选择是「你走过之后，路没了」。分支改变你看到什么，选择改变世界是什么。绝大多数游戏给了大量分支，却没有一个选择。

## 一个定义

necromanov 在比较永恒之柱（PoE）与龙腾世纪 3（DA3）时给了一个非常干净的判据：

**选择 = 一经做出就永久改变世界。**

不是改变过场台词，不是改变任务顺序，是改变世界本身的状态——某个势力不再可结盟、某个 NPC 不再存在、某条路径永久关闭。

按这个定义，DA3 是「有分支无选择」的典型：可以选择阵营、可以选择是否完成任务、可以选择支线，但任务不关心你怎么完成、做了什么决定，主线最终收束到同一个结局。

PoE 则处处是选择：与某个家族拔刀为敌，就丧失了主线结盟的可能；每种打法的难度与收获截然不同；连看似无影响的对话措辞，都会悄悄改变角色的性格，进而影响后续分支。

## 两种结构的对照

| | 分支 | 选择 |
| --- | --- | --- |
| 改变的对象 | 路径、顺序、可见内容 | 世界状态 |
| 可逆性 | 通常可逆，走完能回头 | 不可逆，代价永久 |
| 玩家的记忆 | 记得「我选了左边」 | 记得「我毁掉了那个城」 |
| 成本 | 线性增加（多一条路多一份内容） | 指数增加（状态组合爆炸） |
| 常见误用 | 用分支冒充选择 | 用选择当惩罚 |

最后一行是两种典型的失败：

**用分支冒充选择**，玩家很快就会识破——重开一次发现殊途同归，之后所有分支都失去了重量。

**用选择当惩罚**，玩家会因为「不知道哪个是对的」而不敢选。选择之所以有意义，是因为它两边都有代价，而不是因为一边会被系统惩罚。

## 为什么「选择」这么贵

分支的成本是线性的：多一条路，多做一份内容。

选择的成本是指数的：每一个永久改变世界的决定，都会与之前的决定组合，产生需要处理的状态分支。这是组合爆炸，不是加法。

所以取舍很清楚：

- 分支多的游戏，用分支制造「自由感」，接受没有真正的选择。
- 有选择的游戏，必须限制分支数量，把资源投在少数几个「真的会改变世界」的节点上。

博德 3 走的是后一条路。它的第一章是选择设计的教科书——鬼婆任务有五种完成方式，每种有独特回报，还有投机取巧的解法与后续铺垫。这些不是五条并行的分支，而是五个不同状态的结果。

## 判断一个选择是否成立

三个条件同时满足，才算选择：

- **有代价**。两个选项都要失去什么，不能有一边明显更优。
- **不可逆**。玩家事后无法回退，所以必须承担。
- **被世界记住**。后续内容里能感觉到这个决定还在生效，而不是只在结算画面提一句。

第三条最容易被漏掉。玩家做出选择后如果世界毫无反应，他会怀疑自己是不是点错了按钮。

## 检查清单

- 这个决定之后，世界状态有没有真的改变。
- 玩家重开一次，会发现殊途同归吗；如果会，那这就是分支不是选择。
- 每个选项是否都有代价，还是有一个明显正确。
- 选择是否不可逆，如果可逆，重量从哪里来。
- 后续内容有没有「记得」这个选择。
- 选择的成本是否被评估过，数量是否在可控范围。

## 具体案例

### 永恒之柱：处处是选择

与某家族为敌就永久失去主线结盟可能；每种打法难度与收获不同；对话措辞悄悄改变性格并影响后续分支。这是「选择」的正向样本。

### 龙腾世纪 3：有分支无选择

可选阵营、可选任务、可选支线，但任务不关心怎么完成，主线收束到同一结局。演出、关卡、上手度全面胜过 PoE，却因为丢掉选择而令人失望。

### 博德 3 第一章：五种完成方式的鬼婆任务

五种完成方式各有独特回报，还提供了投机取巧的解法与后续铺垫。不是五条并行分支，而是五个不同状态。
