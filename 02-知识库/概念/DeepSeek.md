# DeepSeek

> DeepSeek 是国内大语言模型，在 [[不用再学代码了！零基础AI全自动做Roblox游戏教程]] 中被用作"Chat 型 AI"代表——能生成 Roblox 脚本供人复制粘贴，但被作者评价为对 Roblox/Luau 代码"以前还不太到位"。

## 核心内容

DeepSeek 在该教程中扮演"向导/顾问"型 AI：用户用自然语言描述需求，DeepSeek 输出完整脚本，由人手动贴回 [[Roblox Studio]]。它代表门槛最低、几乎任何大模型都能做的 AI 开发方式（与豆包、ChatGPT、Gemini、Claude 并列举例）。

作者的实测观察：DeepSeek 在生成怪物动画脚本时反复报错，他判断这与"中文环境下对 Roblox 代码支持以前还不太到位"有关，最终靠人工修正 animation id 解决；相较之下 [[Claude Code]] 在同一任务上"更聪明"（用对了默认行走动画）。这是单次 demo 观察，非基准评测（见待核验）。
