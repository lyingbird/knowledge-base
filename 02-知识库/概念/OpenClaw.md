# OpenClaw

> 2026 年爆红的开源 Agent 框架：本地执行 + IM 入口 + 分层记忆的组合，让「AI 数字员工」第一次看到可用。多位一线人士视之为「划时代的 Agent 框架」，标志 AI 从 Chat 时代进入 Agent 时代。

> ⚠️ 名称待核验：ASR/不同来源出现 OpenClaw / OpenClaude / 小龙虾 等，确切名称与归属（是否 Anthropic 发布、是否被 OpenAI 收购）见 [[03-核验/待核验事实]]。

## 核心内容

综合 [[20个问题搞懂OpenClaw：Agent范式的爆红（十字路口）]] 与 [[罗福莉谈AI范式巨变与OpenClaw（张小珺商业访谈录）]]：

- **本质**：不是聊天产品，而是 Agent 框架 + 运行时环境——本地文件/进程/网络权限 + IM 接入 + 完整反馈循环（运行→出错→自我纠正→重试）+ 多层记忆（原始日志→中期记忆→长期画像）。比喻：ChatGPT 像咨询师，OpenClaw 像实习生。
- **爆红原因**：门槛骤降（从改提示词到聊天框说话）、数字员工承诺第一次可用、开源+社区驱动、创始人社区积累深。
- **超预期**：「惊喜编排」（感知时间的上下文拼接）、持久分层记忆、多模型联合利用、自主任务调度（心跳）、**可被用户自定义修改内部架构**。

## 意义（罗福莉的判断）

- **Agent 框架吃 Post-train**：框架定义「执行规范」，这种规范预训练数据里没有，只能靠人-Agent 多轮交互习得。
- **群体智能自进化**：一百多人在同一框架协作，数小时迭代等于单人数周——这是开源的核心价值。
- **框架能弥补模型短板**：较小模型 + 高质量框架可接近顶尖模型。呼应「记忆 > 智能」。
