# 战略游戏设计

> 战略游戏的根本矛盾是：复杂度越高，对随机性的依赖越强。而随机性是填补设计不足的工具——真正的设计是让玩家在每个时刻都必须计算资源分配，且前面总有更强的敌人。

## 两条评价标准

从三篇素材里能提炼出两条标准，它们互相独立。

**标准一：有没有冷场。** necromanov 对大帝国的评价是「每时每刻计算资源分配、推进无冷场、前面总有更强敌人」。这是正面标准。

**标准二：复杂度与随机性的匹配。** 通常游戏复杂度越高，对随机性的依赖越大（用随机数生成变化性）。因为设计师无法为所有分支手工设计内容，只好让随机数代劳。

两条标准合起来指向一个判断：**随机性用量是设计深度的反面指标。**

## 随机性谱系

necromanov 在分析大帝国时列了一份谱系，很有价值：

| 游戏 | 随机性 |
| --- | --- |
| 围棋、部分桌游 | 无 |
| 魔唤精灵、超级大战争 | 无（但只有单一战术层） |
| 文明 | 几乎无（但有「枪兵捅下直升机」） |
| 火焰纹章 | 战斗无随机，升级凹点随机 |
| 三国志、信长之野望、全面战争、钢铁雄心 | 靠随机 |
| 太空帝国、领土 | 干脆用随机数拼成 |
| 大帝国 | 完全剔除 |

这个谱系有一个反直觉的发现：**无随机性不必然是好事。** 魔唤精灵和超级大战争没有随机性，但它们只有单一战术层——因为一旦引入多层复杂度，无随机性就要求设计师手工设计所有情况。

大帝国之所以罕见，是因为它同时做到了「复杂度高」和「无随机性」——代价是手填了 40 个星域、几百个舰队的数值。

## 无随机性的代价

大帝国证明了这条路可行，也展示了成本。

它的做法：每个敌军星域单独制作有针对性的数套数值，确保玩家无论什么科技等级、什么势力范围，都需要砸锅卖铁调集最有针对性的将领资源。

这是「用人力替代随机数」。成本极高（手填几百个舰队的数值），效果是玩家感到「计算正确就无损」——纯粹的战略乐趣。

## 解决「越玩越简单」

战略游戏的通病是后期乏味：玩家强大了，电脑跟不上，游戏变成走流程。

三个不同的解法：

**解法一：关键点触发。** 大帝国每攻下一个关键星域触发事件，改变敌人结构与玩家可调配资源。美、英、苏三势力各有两关键星域 + 首都作为关键点。

**解法二：电脑发展曲线。** XCOM2 给不同难度电脑设定发展曲线，不管玩家进度如何都按速率投入新兵种，玩家必须规划核心小队成长以跟上。

**解法三：事件逻辑。** 群星用维多利亚式事件逻辑填充后期——人口分化、派系产生、连锁事件。

三种解法的共同点：都在用「外部压力」替代「内部成长」。因为成长到顶后，唯一能维持挑战的就是外部世界的变化。

## 有冷场是设计失败

necromanov 对 P 社四萌的批评值得记录：类别罕见，但「对一般玩家不好玩」——多数时间在等增长，战争操作消磨耐心。

「等增长」是战略游戏最常见的冷场形式。玩家没有决策可做，只是等一个数字涨上去。

对比大帝国的标准：每时每刻计算资源分配。这才是理想状态。

## 检查清单

- 玩家在每个时刻有没有需要计算的决策。
- 有没有「等增长」的空转期。
- 随机性用量是否与设计深度成反比。
- 复杂度上升时，是用随机数还是用人力填补。
- 后期靠什么维持挑战（关键点/发展曲线/事件）。
- 前面是不是总有更强的敌人。

## 具体案例

### 大帝国：无随机性的极端

手填 40 个星域、几百个舰队的数值。玩家计算正确就无损。代价是设计成本极高。

### 群星：事件逻辑填后期

人口随科技与帝国扩大分化，产生派系与连锁事件。《文明开化》事件树的后继分支（独立战争/投靠/核战废土/蟑螂提升）。

### XCOM2：电脑发展曲线

不同难度设定不同发展速率，玩家必须跟上。比真实电脑发展模型（三国志 13）更安全稳妥。
