# 明末：渊虚之羽

> 成都灵泽科技 2025 年发售的国产类魂 ARPG。战斗系统（须羽循环 + 抗衡机制）拿到 IGN 8 分的「类魂阵营佳作」评价，第一章蜀王祠箱庭被老玩家认可「学到了魂的精髓」；但发售首日因优化崩溃、定价区服错误、预购奖励错发三大运营失误叠加剧情争议，Steam 好评率跌至 19%，最终销量不及预期、团队解散、IP 易主。它是「产品及格线以上、发行灾难以下」的完整样本，也是国产 3A 第二棒交出的最贵学费。

开发六年。团队用激光扫描仪与无人机复原安岳毗卢洞、桃坪羌寨、平武报恩寺等数十处四川古迹，把川剧变脸、皮影戏、竹笋怪、熊猫侠 NPC 等地域符号织进关卡——制作人夏思源的表述是「好的玩法是骨头，但作品的肌肉和灵魂永远是文化的表达」。

## 战斗系统：须羽循环与「让玩家当 Boss」

### 须羽（资源循环）

类魂框架下最核心的创新：**完美闪避、弹反、特定武器招式积攒「须羽」层数**，用于释放武器战技、流派技能与法术（羽灵/火焰/冰霜多属性）。它把传统魂系的防御动作从「保命手段」改写为「进攻资源」——「闪避-积攒-爆发」闭环，IGN 称其「打破类魂伺机而动的定式」。常规闪避自带超长无敌帧，对新手相当友好。

### 五武器与抗衡

单手剑（自动恢复须羽）、双刀、长刀、大斧、长枪各带独立天赋树与武器技能，可装备两把随时切换，流派技能独立搭配，神龛免费洗点——Build 深度对标的是「 Build 党」而非纯魂玩家。

双刀的**抗衡（Clash）机制**是 Polygon 评测标题的来源：「让玩家当 Boss」——与敌人对砍抵消大部分伤害，配合「自心剑意」流派技能（剑意 buff：提升攻速 + 抗衡回血），可以硬扛 Boss 一套连招全身而退。它给出的体验不是魂系「等待窗口」，而是正面互换，这让主角无常完全脱离了魂式「防低血薄一捏就死」的模板。

### 心魔系统

杀无变异人类敌人涨心魔值（HUD 左下角量表，涨到一定程度眼睛变红）；满值后攻击提升、受伤也提升，是有意保留的高风险开关。跑尸时地图刷新心魔幻影，击败才能捡回经验——但死亡本身不清空经验值，跑尸的必要性被大幅稀释，这是对魂式死亡惩罚的一次温和化改造。争议也在这里：心魔是「又香又臭」的机制（Polygon 原话），降低它要消耗品 + 特定场所。

## 关卡设计：学到了魂的结构，没学会魂的节奏

**正面**：以蜀王祠为核心的第一章是教科书级箱庭——多层次回环、单向门与隐藏岔路环环相扣、一个核心篝火撑起整张图、从起点可徒步抵达最终 Boss；云顶内城竖井纵向嵌套、佛源镇辐射式铺开。捷径密度约为同类作品 1.5 倍，杜鹃鸟提示捷径的细节被广泛称赞。

**反面**：同一套「原教旨主义」在节奏调控上失灵。转角炸药桶、一碰即碎的机关地板、伪装成篝火的偷袭怪、雪地地雷、叠加 debuff 的地下区域——IGN 西班牙的评价最为尖锐：**关卡设计常常令人抓狂，「套路式难度」通过陷阱、伏击和阴招让玩家莫名死亡，是「刁难而非挑战」（harassment, not challenge）**；并给出著名建议：「若能把区域结构简化 50%、Boss 战增加 20%，评价会高得多。」Boss 难度波动同样过大：既有招小怪的混子 Boss，也有卡关数小时的墙（多阶段是常态，部分三阶段）。

这组对照是本页最重要的设计教训：**箱庭结构可以复制，但「恶意」必须服务于「挑战-成长」循环，而不是流程延长的手段。**详见主题页 [[国产3A动作游戏三连]] 判断二。

## 发售灾难与口碑修复时间线

| 时间 | 事件 |
| --- | --- |
| 2025-07-24 | 发售，首日 Steam 峰值在线约 13 万，登顶全球热销榜；好评率跌至 **19%**（首日差评 8867 条） |
| 07-25 | 1.3 补丁：显存管理优化、修复奖励错发、削减第二章地雷 |
| 07-26 | 1.4 补丁：帧率稳定性修复（4090 可流畅 2K） |
| 07-28 | 单日好评反超差评，总好评率 41% |
| 08-04 | 好评率 46-47%，1.4.1 热修 + 预告 1.5 |
| 08-11 当周 | 1.5 版本：起身无敌帧、喝药加速、明军 NPC 不再主动攻击（剧情调整又引发新争议） |
| 08 底 | 近期好评率 71% |
| 09 下旬 | 1.6 版本发放豪华版补偿；近期好评率稳定 81%+，「特别好评」 |

**三大首发失误**（全部是运营层面而非产品层面）：优化崩溃（4090 2K 卡顿）、国区 248 元意外成为全球最高价区、标准版玩家领到了豪华版专属奖励（预购玩家被背刺）。叠加 PS5 实体版偷跑后的剧情争议——「几乎没有清军形象」与部分玩家「反清复明」预期不符，被上升为立场指控——舆论迅速脱离游戏本身。

## 商业结局：销量、解散与 IP 易主

销量口径混乱且互相冲突，需谨慎引用：第三方 VG Insights 估算两周 150 万→210 万份（营收约 8460 万美元）；而 2025 年国游销量年榜统计仅 **126 万份**；发行方财报修正后 Steam 实际约 140 万+。可以确认的是：**未达到 200 万+ 的普遍预期，仅勉强回本**（研发成本未公开，但对比同档国产 3A 投入属于失手）。官方口径的「玩家总数突破 500 万」包含 XGP 与 PS Plus 订阅触达，不是销量。

更沉重的结局在发售后八个月内发生：2026 年初灵泽把项目组转外包的计划引发冲突，**夏思源被无预警开除**（技术入股多年未领工资），核心团队解散、欠薪仲裁；2026-04 发行商 Digital Bros 收购 IP 全部知识产权；2026-07-29 官宣夏思源新工作室「递归海豚」与 Digital Bros 签约，无常系列新作立项（初始投资 2150 万欧元，505 Games 全球发行、成都设分部）——**IP 回到了creator 手里，但初代团队已经不存在了。**

## 夏思源复盘（2026-08 访谈）

- 危机阶段无暇纠结情绪：「第一优先级是修复游戏问题、处理玩家反馈，保障项目正常推进。」
- 承认「滑跪式更新」的教训：首次开发大体量单机，海量反馈集中涌入只能优先紧急修复，难以全局平衡；续作要「区分表层诉求与底层诱因，不单一修改内容」。
- 与发行方完成了预购、海外定价等发行漏洞的复盘。
