# 涌现式游戏设计

> 席德梅尔的「游戏是一连串有意义的选择」，是对这个设计理念最精炼的概括。涌现式设计的反面不是「不自由」，是「每个资源只服务一个系统」的拼接结构。

## 定义

涌现式玩法（Emergent Gameplay）描述这样一种设计：系统与资源不严格隔离，彼此碰撞出未知的化学反应。

necromanov 列的代表作：矮人要塞、Rimworld、文明、十字军之王、万智牌、辐射、太吾绘卷、旷野之息。

这份名单的一个重要特征是它跨越了类型——有模拟经营、4X、卡牌、RPG、开放世界。说明涌现不是某个类型的属性，是一种结构特征。

## 与拼接式的根本区别

| | 拼接式 | 涌现式 |
| --- | --- | --- |
| 资源归属 | A 系统的资源只用于 A | 资源跨系统流通 |
| 设计方式 | 预设流程与结果 | 定义规则，观察结果 |
| 控制手段 | 数值、经济、出口 | 规则约束 + 裁剪 |
| 优点 | 可控、可预算、易平衡 | 意外多、重玩价值高 |
| 缺点 | 缺乏意外、易罐头化 | 难平衡、裁剪成本高 |

necromanov 的措辞是：拼接式「易设置卡点但缺乏意外」，涌现式「追求裁剪」。

这个对比的关键在于「控制」的位置。拼接式在设计期控制，涌现式在运行期观察、在后期裁剪。

## 为什么涌现难做

三层难度，逐层上升：

**第一层：让系统真的能互相作用。** 这需要在架构上取消系统隔离，让资源可以跨系统流通。技术上不难，难的是接受「设计者不能预知所有结果」这件事。

**第二层：让玩家发现这些作用。** 系统能碰撞，但玩家不知道，等于没有。这需要引导——旷野之息用系统广度和新手区的密集反馈解决。

**第三层：裁剪危险的组合。** 这是最难的一层。玩家会找到设计者没想到的组合，其中一部分会破坏体验。

RDR2 的例子很典型，necromanov 列了四种不同的问题类型：

- 城里纵马撞人被通缉——物理碰撞与非敌意 NPC 的受伤逻辑没有做保护。
- 任务后翻尸体突然被通缉——目击与通缉的链接没有在该断的地方断。
- 狩猎熊皮只能放一件——为了多人偷窃玩法做的限制，在单人里荒谬。
- 上马与攻击同键、抢劫与掏枪只差按键顺序——UI 层没有处理好多功能复用的意图判断。

四种问题的共同点是：它们都不是设计不够大胆，是收尾工作没做完。

## 技术进步拆掉了「系统墙」

necromanov 的核心判断：家用机时代的硬性「系统隔断」正在被技术进步拆除。

过去的隔断是技术与性能限制的产物：

- 解谜时不能战斗，因为需要切换两套系统。
- 战斗时不能对话，因为对话系统与战斗系统互斥。
- 场景之间需要读盘，所以要做「安全区」。

现在这些限制消失了：NPC 可以语音交流，战斗与非战斗场景一致，ARPG 与 RPG、射击与 RPG 的界限模糊。

于是涌现式设计重新可行。necromanov 举的例子：

- PUBG = 生存 + 搜集 + 驾驶 + 射击的涌现。
- 堡垒之夜 = PUBG + 建造。

他的推论是：空旷巨大的开放世界，必然要靠涌现设计填满——因为没有足够的人力手工填。

## 长板遮掩短板

这是 necromanov 对风险的回答：即便裁剪有风险，涌现式玩法在未来仍利大于弊，「当木桶长板足够长，它可以遮掩一切短板」。

必须理解这个前提。RDR2 的裁剪漏洞能被接受，是因为它的细节密度与叙事质量撑住了。如果长板不够长，同样的漏洞就是致命的。

所以这条判断的正确读法不是「涌现可以不管短板」，而是「涌现的长板足够长时，短板可以被容忍」。

## 检查清单

- 资源是否跨系统流通，还是各系统自守。
- 玩家有没有途径发现系统间的组合，引导是否到位。
- 破坏性的涌现组合是否被裁剪，四类问题（物理碰撞、状态链接、多人/单人差异、UI 复用）是否都检查过。
- 长板是否足够长，足以遮掩裁剪漏洞。
- 这个项目的规模，人力够不够手工填充，还是必须依赖涌现。

## 具体案例

### RDR2 的 LT 交互菜单

把瞄准键转化为依对象而变的多选菜单（抢劫/问候/买卖/逼问/喂马），盘活法律系统、目击者、打猎等深层逻辑。necromanov 说最厉害的交互创新是让玩家感觉不到创新——多数玩家没意识到这是 GTA5 里根本没有的设计。

### 太吾绘卷：中国市场的验证

百万销量，证明涌现式理念在中国市场有新机会。necromanov 把它列为代表作之一。

### 拼接式厂商的反向操作

necromanov 指出：擅长 RPG 的厂商反而在砍掉多分支互动，以满足「一键交互」的伪需求。这是把拼接式当成进步的方向性错误。
