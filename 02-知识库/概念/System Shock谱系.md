# System Shock谱系

> 一条从 Looking Glass 到 Arkane 的传承线。它的价值在于一个判断：原作伟大但艰涩，精神续作（Deus Ex / BioShock / Prey）的实现水平远好于原作——因为原作者有天才设计，却缺同样天才的关卡、UI、程序、美术。

## 源头

Looking Glass，2000 年破产。

necromanov 的评价非常精准：有天才设计师，但缺同样天才的关卡/UI/程序/美术。

这句话解释了为什么 System Shock 系列「伟大但艰涩」——设计构想超前，但执行层面跟不上。

## 传承线

necromanov 画的谱系：

System Shock → Deus Ex / BioShock / Prey。

三个后继者的共同点：**它们都比原作「好玩」。**

这个判断有点反直觉。通常我们会认为「原作最纯粹，续作妥协了」。necromanov 的看法相反：

原作伟大但艰涩；精神续作的实现水平远好于原作。

## 为什么续作更好

原因可以归纳为三条：

**原因一：技术成熟。** 原作受限于当时的技术（3D 引擎、UI 框架、输入设备）。续作可以用更好的工具实现同样的构想。

**原因二：设计经验积累。** 二十年间，行业学会了怎么做沉浸模拟的引导、怎么做 UI、怎么控制复杂度。

**原因三：可参考的先例。** 续作者可以玩原作，知道哪些设计有效、哪些艰涩。

第三条最容易被忽略。**原作的失败经验本身就是遗产。**

## 「艰涩」的具体含义

这个词需要展开，否则会被误解成「老游戏不好操作」。

系统冲击的艰涩属于结构层：

- 界面复杂（大量按键、多层菜单）。
- 信息密度极高（需要读大量文本）。
- 没有引导（玩家要自己摸索规则）。
- 失败惩罚重（早期资源紧张）。

这四条在 1994 年是「深度」，在 2017 年是「门槛」。

## 谱系的两支

值得注意：Deus Ex 和 BioShock 走了不同的路。

| | Deus Ex 一支 | BioShock 一支 |
| --- | --- | --- |
| 侧重 | 系统自由（多路径解决问题） | 叙事氛围（世界观与演出） |
| 关卡 | 多条路线，多解 | 相对线性，演出驱动 |
| 玩家身份 | 有能力的行动者 | 被引导的见证者 |

Prey 属于前者（Deus Ex 一支）。necromanov 称其为「最好的网络奇兵精神续作」，理由正是它重建了系统自由与迷宫结构。

## 检查清单

- 继承的是构想还是形式。
- 有没有用当代技术解决原作的艰涩。
- 有没有吸收原作的失败经验。
- 属于 Deus Ex 一支还是 BioShock 一支。
- 关卡是「多解」还是「演出驱动」。

## 具体案例

### Looking Glass：天才设计 + 不足的执行

2000 年破产。有天才设计师，缺同样天才的关卡/UI/程序/美术。

### Deus Ex：系统自由一支

多条路线、多个解法、有能力的行动者。

### BioShock：叙事氛围一支

相对线性、演出驱动、被引导的见证者。

### Prey：回到系统自由

necromanov 称其为最好的网络奇兵精神续作。
