# 化学引擎与系统涌现

> 「化学引擎」不是指某个具体系统，是指系统之间能够互相反应的设计结构。它和「物理引擎」的区别是：物理引擎保证物体不穿模，化学引擎保证世界会给你意想不到的回应。前者是正确性，后者是可能性。

## 两个词先分清

**系统涌现**是结果：简单规则互相作用，产生设计者没有预先写出的行为。矮人要塞、Rimworld、文明、十字军之王、万智牌、辐射、太吾绘卷、旷野之息都被 necromanov 归入此类。

**化学引擎**是手段：刻意设计一套系统间相容、可互相作用的结构，让涌现更容易发生。

所以化学引擎是「怎么造」，系统涌现是「造出来会怎样」。前者可控，后者不可控——这个区别是全部难点的来源。

## 化学引擎的构成

旷野之息的系统清单是一个好样本：攀爬、烹饪、战斗、潜行、火焰、冻结、雷电、风力、天气、气温、炸弹、磁力、冰块，十余个系统。

关键在于这些系统之间是**相容**的，而不是各自孤立：

- 火焰遇到草地会蔓延，遇到雨天会熄灭，遇到上升气流会改变方向。
- 雷电在雨天更容易击中金属装备。
- 冻结可以造冰柱，冰柱可以当垫脚石，也可以砸下来。
- 温度影响角色状态，也影响食物效果。

这些交互不是「火焰系统自己实现的功能」，是系统之间碰撞出的结果。设计者定义了规则，但没有写出所有结果。

## 与拼接式设计的对照

necromanov 用「线性/拼接式设计」做了对照：

| | 拼接式 | 涌现式 |
| --- | --- | --- |
| 资源 | A 系统的资源只用于 A 系统 | 资源跨系统流通 |
| 控制方式 | 控制数值、经济、出口 | 定义规则，观察结果 |
| 卡点设置 | 容易（直接限制） | 困难（要管住组合） |
| 意外 | 少 | 多，有些是好事，有些是灾难 |
| 主要风险 | 无聊、可预测 | 失控、破坏平衡 |

拼接式设计的代表是绝大多数 3A。它可靠、可预算、可按甘特图推进。涌现式设计的代价是不可预测——你不知道玩家会做出什么。

## 裁剪：最难的部分

necromanov 反复强调这一点：涌现式设计最难的不是让系统碰撞，而是**收束危险的涌现组合**。

他用 RDR2 举了一串例子，都是「裁剪没做好」的后果：

- 城里纵马撞人被通缉——马的碰撞与非敌意 NPC 受伤没有做保护。
- 任务后翻尸体突然被通缉——目击与通缉的链接没有切断。
- 狩猎熊皮只能放一件——这是为了多人偷窃玩法做的限制，在单人里变成了荒谬。
- 上马与攻击同键、抢劫与掏枪只差按键顺序——这是涌现未优化 UI 连接关系的恶果。

这些都不是设计不够大胆，是收尾工作没做完。涌现系统上线后，玩家会找到设计者没想到的组合，其中一部分会破坏体验，必须逐一封堵或引导。这个工作量随系统数量呈组合增长。

## 为什么系统广度反而改善初期体验

这是旷野之息最反直觉的发现，值得单独说。

直觉是：新手区要简单，所以系统要少，一次教一个。

旷野之息的做法相反：一开始就给你十几个系统，新手区里火焰系统就有六种以上用法。

结果初期体验反而更好。原因是：

- 系统越多，可用的解法越多，玩家卡住的概率越低。
- 玩家不需要学完所有用法，只需要知道「试试可能有反应」。
- 每次意外成功都是一次正反馈，而正反馈是留存的关键。

前提是每个系统都必须有真实的深度，不能是摆设。如果某个系统只有一种用法，它不增加解法，只增加认知负担。

## 技术进步拆掉了「系统墙」

necromanov 的另一条判断：家用机时代的硬性「系统隔断」正在被技术进步拆除。

- 过去解谜时不能战斗，战斗时不能对话。
- 现在 NPC 可以语音交流，战斗与非战斗场景一致，ARPG 与 RPG、射击与 RPG 的界限模糊。

这使涌现式设计重新可行。PUBG 是生存 + 搜集 + 驾驶 + 射击的涌现，堡垒之夜是 PUBG + 建造。空旷巨大的开放世界，必然要靠涌现设计填满——因为没有足够的人力去手工填。

他的结论是：即便裁剪有风险，涌现式玩法在未来仍利大于弊。「当木桶长板足够长，它可以遮掩一切短板。」

这句话有个隐含前提：长板要真的够长。RDR2 的细节密度与叙事质量撑住了它的裁剪漏洞；如果长板不够，同样的漏洞就是致命的。

## 检查清单

- 系统之间是相容还是孤立，A 的资源能不能用于 B。
- 每个系统有几层用法，只有一种用法的系统是否值得存在。
- 有没有为涌现结果做裁剪：玩家可能做出的破坏性组合是否被封堵或引导。
- UI 层有没有处理好系统的连接关系（一个键触发多个功能时的顺序与意图判断）。
- 长板是否足够长到可以遮掩裁剪漏洞。
- 如果做开放世界，人力是否够手工填充，还是必须依赖涌现。

## 具体案例

### 旷野之息的火焰系统

新手区就有六种以上互动用法。火焰在草地蔓延、在雨天熄灭、遇上升气流改变方向。这些不是写死的脚本，是系统碰撞的结果。

### RDR2 的 LT 交互菜单

把瞄准键转化为依对象而变的多选菜单（抢劫/问候/买卖/逼问/喂马），盘活了法律系统、目击者、打猎等深层逻辑。necromanov 说最厉害的交互创新是让玩家感觉不到「创新」——多数玩家没意识到这是 GTA5 里根本没有的设计。

### RDR2 的裁剪失败案例

纵马撞人被通缉、翻尸体被通缉、熊皮只能放一件、上马与攻击同键。这四种问题类型不同，但都指向同一件事：涌现系统上线后，收尾工作没做完。
