# 卡牌游戏设计起源

> 今天手机卡牌游戏的设计源头，是 2002 年世嘉街机 WCCF 发明的「账户 + 集换式街机卡牌」。这条传承线经过 DeNA、Gree、Mixi，最终成为移动卡牌品类。

## 一条被忽略的传承线

necromanov 的这个判断容易被当成冷知识，但它的方法论意义很实在：一个今天看来「天然属于手机」的品类，源头在完全不同的载体上。

WCCF（World Club Champion Football）是世嘉 2002 年的街机作品。它的设计创新是「账户 + 集换式街机卡牌」：

- 玩家有一个持久账户，记录自己的队伍与资产。
- 卡牌是实体卡片，从街机机器产出。
- 卡片可以在玩家之间交易。

这三条合起来，就是今天所有卡牌手游的骨架：持久身份、随机获得的收集品、玩家间的流通。

## 为什么这在街机上成立

街机的物理形态恰好适配这套设计：

- 实体卡片是天然的稀缺品，摸得着，有收藏价值。
- 街机厅是天然的社交场所，面对面交易比线上更有信任感。
- 投币机制天然适配「抽卡」——投一枚，出一张，随机性带来的期待与多次投币的循环。

第二条尤其重要。卡牌的乐趣有一半在交换，而交换需要信任与场所。街机厅同时提供了这两者。

## 迁移到移动端

经 DeNA、Gree、Mixi 发扬，这套设计变成了移动卡牌品类。

迁移过程中丢掉的和保留的：

| 要素 | 街机 | 移动端 |
| --- | --- | --- |
| 持久账户 | 街机账户 | 游戏账号 |
| 收集品 | 实体卡片 | 虚拟卡牌 |
| 随机获取 | 投币出卡 | 抽卡（gacha） |
| 玩家交易 | 面对面 | 部分保留，部分取消 |
| 社交场所 | 街机厅 | 公会、聊天、社区 |
| 稀缺性 | 实体天然稀缺 | 需要人为设计 |

最后两行是迁移中损失最大的部分。实体卡片的稀缺性天然存在，虚拟卡牌需要靠概率与产能人为制造；街机厅的面对面社交无法直接复制，只能靠公会与聊天近似替代。

损失这两项之后，卡牌品类的乐趣结构发生了变化——从「收集 + 交换 + 对战」变成「抽卡 + 养成 + 对战」。交换这一环在很多产品里被彻底移除了。

## 街机作为设计实验室

necromanov 还提了一个更宏观的观察：日本街机厅像「平行世界游戏展」——MOBA、策略卡牌、FPS/TPS、抽卡 + X、舰娘都在街机运行，品类健康度甚至优于中美手游市场。

这个观察的价值在于它提出了一种可能：街机是一个低成本验证品类的场所。

- 硬件统一，开发目标明确。
- 用户当场付费，反馈即时。
- 单店试运营成本远低于全球发行。

所以很多后来在移动端或 PC 端爆发的品类，先在街机里被验证过。WCCF 是一个例子，格斗游戏是另一个。

## 检查清单

- 收集品是否具备天然的稀缺性，还是需要人为制造。
- 有没有交换机制，交换需要什么条件（信任、场所、规则）。
- 持久账户承载了什么（进度、资产、身份）。
- 随机获取的期待感来自哪里，成本是否可控。
- 迁移到新载体时，丢掉了哪些环节，是否需要补回。

## 具体案例

### WCCF：2002 年的账户 + 集换式卡牌

持久账户、实体卡片、玩家交易。三条合起来是今天卡牌手游的骨架。

### DeNA / Gree / Mixi：迁移的桥梁

三家把街机卡牌的设计语言搬到移动端，形成移动卡牌品类。迁移中丢掉了实体稀缺性与面对面社交。

### 街机厅：平行世界游戏展

MOBA、策略卡牌、FPS/TPS、抽卡 + X、舰娘都在街机运行。品类健康度甚至优于中美手游市场。
