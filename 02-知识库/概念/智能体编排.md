# 智能体编排

> 智能体编排（Orchestration）是 AI 时代的新稀缺品：不是拥有多少能力或多少工具，而是能用什么样的工作流，把多个智能体集群串联成一支协同完成复杂目标的"虚拟团队"。

## 核心判断

"未来的稀缺品，从来不是能力，是编排。" 一人独角兽不是"一个人加一堆工具"，而是"一个人加一支被编排好的智能体团队"——后者比前者难得多。

观察到的反直觉现象：会用 20 个 AI 工具的人，往往做不出比只会用 3 个工具的人更好的东西。差距不在拥有多少能力，而在能用什么工作流串联它们。

## 编排的认知基础

人的工作记忆约 4 个组块（Cowan, 2001）。[[智能体]] 不改变这个生理上限，而是放大每个"组块"内的能力密度——指挥家不需要会演奏每件乐器，而是编排整支乐队。一个人能调度的从 4 个任务变成 4 个智能体集群。

## 常见编排模式

- **AI + 垂直知识库**：领域知识构建为向量库，AI 优先检索，让一人"掌握"小公司级知识资产（对应 [[团队知识库]] / [[企业上下文]]）。
- **LLM Router + 专业模型**：调度层按难度/任务类型分流到不同模型，平衡成本与质量。
- **AI 流水线**：把任务拆成多阶段，每阶段专门工具负责，人当"总导演"监督质量而非执行细节。
- **组织级编排**：把 Agent 接管中层转译协调，沟通即执行——参见 [[超级组织]] 的 Code Banana 实践。

## 与已有概念的关系

- 编排是 [[智能密度]] 在个体/小团队尺度的具体能力：智能密度衡量"系统压缩智能的能力"，编排是把这种能力落到可执行工作流。
- 编排是 [[AI超级个体]] 和 [[一人公司]] 的核心技能，也是 [[AI原生工作流]] 在个人尺度的体现。
