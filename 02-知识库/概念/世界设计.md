# 世界设计

> 世界设计是把空间布局、进度结构、叙事主题、玩家记忆和可选内容组织成一个可被探索的整体，而不是把关卡区域顺序拼接起来。

## 核心判断

- 好的世界设计要回答“这个地方为什么存在”和“它为什么在这里”。区域之间的关系越能被玩家理解，世界越容易形成整体感。
- 世界地图可以承担叙事功能。上升、下潜、绕行、回到旧地、旧地被改变，都是空间层面的故事表达。
- 早期世界可以更线性，让玩家学会目标、地图、能力和障碍；中后期再增加分叉、秘密和回溯奖励。
- 世界设计的深度来自多层可读性：主线可读、支线可追、秘密可猜、高手路线可破序。

## 设计杠杆

- 目标：给玩家一个足够清楚的方向，例如抵达某个高处、逃离某个区域、寻找某个中心地点。
- 节奏：在线性推进和自由探索之间切换，避免一直赶路或一直迷路。
- 空间叙事：让地图形状服务主题，例如朝圣、坠落、深入、污染扩散或边境开拓。
- 回溯：新能力让旧区域重新有意义，但不一定强迫所有玩家频繁返回。
- 秘密：地图可以提示大方向，但不要把所有发现都 UI 化。

## 具体案例

### 一个可用的检验：地图为什么要存在于这里

好的世界设计要回答"这个地方为什么存在"与"它为什么在这里"。区域之间的关系若能形成"因为……所以必须经过这里"的因果，世界才整体。

### 艾尔登法环：主线的空间即叙事

从出生点到最终胜利的路径设计包含上升、下潜、绕行、回到旧地、旧地因进程而改变。玩家在空间里走完，等于把时间线走了一遍。

### 世界设计深度：多层可读

好的世界是主线可读、支线可追、秘密可猜、高手可破序。用户在做世界设计时可照此分层自检，每一层都要有自己的「为什么」。

### 注意

世界设计的具体可回查案例较少，因为它是空间与叙事的综合。上面这三条是可复用的判断框架，实际案例建议读者从 Hollow Knight 的地图互锁与 Elden Ring 的路径因果中自行体验验证。
