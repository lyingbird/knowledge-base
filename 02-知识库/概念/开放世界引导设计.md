# 开放世界引导设计

> 开放世界的引导有两种：用 UI 把内容喂给玩家，或者用世界本身让玩家自己走过去。前者是任务列表，后者是关卡设计。区别不在易用性，在探索这件事有没有被设计过。

## 高度地标体系

旷野之息的引导体系是一套逐级降低的层级结构。necromanov 的梳理如下：

| 层级 | 数量 | 可见性设计 |
| --- | --- | --- |
| 高塔 | 14 座 | 光芒穿透天候，强行出现 |
| 明显神庙 | 40-50 个 | 视觉上明显可辨 |
| 隐藏神庙 | 其余 | 分 5-6 级隐藏程度 |
| 小地点 | 种子、宝箱 | 设计不同隐藏等级，几乎无无提示地点 |

关键在于最下面一行：**几乎不存在无提示地点**。每个可发现的东西都有一层提示，只是提示的强度不同。

这否定了一种常见误解——以为「开放世界的乐趣在于藏东西」。藏得再好，玩家找不到就是无效内容。真正的做法是分级提示：容易的给强提示，难的给弱提示，但没有一个是零提示。

## 地形本身作为限制

另一条常被忽略的设计：每座山的每一面，都有一个「设计最低需要体力值」。

如果玩家的体力不够，设计者会准备替代方案——上升气流、歇脚平台。这意味着：

- 攀爬不是「随便爬」，是有成本门槛的。
- 门槛不是硬门，是可以用准备绕过的软门。
- 每条路都被设计者走过一遍，并在走过的地方留下了补给。

这是把地形做成关卡的具体方法。它比「这里是山，爬不上去」复杂得多，也比「这里有一扇需要钥匙的门」自然得多。

## 京都地图与倒置

一个有趣的事实：海拉尔地图是京都地图倒置。海丽亚河对应桂川，悟山对应已故社长岩田聪。

这个事实的意义不在于考据，在于它说明设计方法的来源：任天堂总部所在的京都，是一座严格建筑高度控制的山城。在这样的城市里生活，视觉上天然形成「远处有高点、近处有遮蔽」的空间经验。

把一座真实城市的空间结构倒置过来，得到的是一个「每处都能看到远处高点」的世界。这解释了为什么旷野之息的视野设计如此自然——它不是在空旷平原上人为放置地标，是从一个本就有层级的城市骨架里长出来的。

## 加法而非减法

necromanov 的判断很明确：荒野之息是加法，不是减法。

它用关卡设计实现了别人用地点列表、文字、脚本完成的工作。

对比一下：

| | 常见开放世界 | 旷野之息 |
| --- | --- | --- |
| 告诉玩家去哪 | 任务标记、文字提示 | 地标可见性 |
| 告诉玩家能做什么 | 教程、UI 弹窗 | 系统可用性与反馈 |
| 限制玩家进度 | 等级门槛、任务锁 | 体力门槛、温度、敌人强度 |
| 内容发现 | 地图上的问号 | 分级提示的藏匿 |

这套做法的成本极高——它要求关卡团队把整个世界走一遍，并在每处留下设计。但它得到的东西也很实在：玩家感觉自己在探索，而不是在执行。

## UI 不是问题所在

necromanov 有一个重要澄清：问题不在 UI 易用性。

他举例说艾尔登法环也加了传送大地图、光柱引导、NPC 图标。这些 UI 辅助并不会破坏探索感。真正的问题是：探索本身有没有被设计过。

如果一个世界只是把内容撒在地图上，那再好的 UI 也只是在给玩家指路去一片空地。反过来，如果每处都有设计，UI 辅助只是节省了走路时间。

判断标准可以这样表述：**关掉所有 UI，这个世界还能不能引导你**。旷野之息可以（地标、地形、光线）；很多开放世界不行。

## 检查清单

- 世界里有没有层级化的地标，最高层级的能否穿透天气/距离被看到。
- 可发现的内容有多少是零提示的，这部分占比是否过高。
- 地形是否有「设计最低需要的资源值」，以及对应的替代路径。
- 限制玩家进度用的是硬门还是软门。
- 关掉 UI 之后，世界还能不能引导玩家。
- 引导的成本是否被算进预算，还是被当成「关卡团队顺手做」。

## 具体案例

### 旷野之息：高塔的光芒

14 座高塔的光芒能穿透天候，在任何位置都能看到。这是「最高层级提示」的设计——不管玩家在哪、天气如何，总有一个方向是明确的。

### 初始高地：安全的起步盒

几乎没有人工门，所有教学都靠「这里的温度会杀死你」这类世界自身的规则。探索动线被做成了世界规则的学习过程，而不是任务清单。

### 艾尔登法环：UI 辅助不破坏探索

加了传送大地图、光柱引导、NPC 图标，探索感依然成立。说明 UI 不是问题，探索有没有被设计才是。
