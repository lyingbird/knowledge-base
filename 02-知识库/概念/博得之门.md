# 博得之门

> 1998 年的博得之门确立了一套设计范式，影响了此后大半西洋 RPG 的思路。二十五年后，博得之门 3 用同一套核心（选择 + 挑战）配上当代技术，成了这个范式最强的证明。

## 1998：确立范式

necromanov 的记录：博得之门（1998，Bioware / Black Isle）继承 DND 全盛规则。

它提供的东西清单很长：自由复杂的角色创建、即时战略式操作、多变任务、自由地图、主城、对话树、完整 NPC。

necromanov 的判断：影响日后大半西洋 RPG 思路。

这个判断的具体含义是：博得之门把「DND 规则 + 小队 + 即时暂停」这三样组合成了可复制的模板。此后二十年的美式 RPG 都在这个模板上做变体。

## 对产业的外溢效应

necromanov 在分析辐射时提到一句：博得之门的销量孕育了 CDPR。

这句话说明这个 IP 的影响力超出了游戏本身——它证明了一个「小众类型」可以有足够大的商业成功，从而支撑新的团队进入。

## 永恒之柱：忠实到连 BUG 都投影

PoE 的定位是「博得之门的投影」。

necromanov 的评价很传神：黑曜石（黑岛破产后的难民）用 Kickstarter 赞助的数百万元开发，忠实到连画面风格和 BUG 也投影过来。

系统层面是「创意 + 致敬」的混合：

- 八成法术能找 DND 对应（改名致敬）。
- 牧师、圣骑士加神界 3 式的「性格」系统，信仰/教条影响能力。
- 吟游诗人的歌变成「蓄气」资源。

「投影」这个词的选择很精确：不是复刻，是把原作的影子投射到新技术上。

## 2023：博得之门 3

二十五年后的续作，用同一套核心配当代技术。

表现：两周 520 万、Steam 同时在线 87 万、MC 第 8。

necromanov 的讽刺式观察：「大卖后会被开除 CRPG 籍」——上古 5、辐射 3、巫师 3、博得 3 皆如此。

这个现象说明一个规律：**当一个类型的核心乐趣被验证为「普世有效」，它就不再被当作该类型专属。** 博得 3 卖爆后，人们说它是「RPG」而不是「CRPG」。

## 两代之间的关系

必须说清楚：博得 3 不是博得 1/2 的延续，是同一范式的第三次实现。

三代的差别：

| | 博得之门 1/2 | 博得之门 3 |
| --- | --- | --- |
| 规则 | DND 2E（THAC0 时代） | DND 5E |
| 战斗 | 即时暂停 | 回合制 |
| 演出 | 2D 等距 + 文本 | 全 3D + 动捕 + 语音 |
| 选择密度 | 高 | 第一章极高，第三章下降 |

第四行的下降是关键（见 [[选择取向]]）。它说明即使在同一范式内，选择的密度也会因为内容量压力而衰减。

## 检查清单

- 核心范式是什么（选择 + 挑战 + 规则透明）。
- 新技术是服务于范式，还是替代了范式。
- 选择的密度是否随内容量增加而下降。
- 是否有「大卖后被开除类型籍」的现象（说明核心乐趣被验证）。
