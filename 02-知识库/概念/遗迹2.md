# 遗迹2

> 魂系射击的解法不是把魂的难度调低，而是把「这一次遇到什么」变成随机的：世界层抽剧情、场景层拼地牢、每张图钉一个手工锚点。它真正创新的地方不在战斗，在于用互斥内容把「重复游玩」从玩家自发的行为，改成了设计的必然结果。

## 基本盘

| 项 | 内容 |
| --- | --- |
| 开发 / 发行 | Gunfire Games / Gearbox Publishing（后更名 Arc Games） |
| 发售 | 2023-07-25，PC / PS5 / Xbox Series X\|S |
| 引擎 | Unreal Engine 5 |
| 总监 | David Adams（Gunfire CEO） |
| 类型 | 第三人称射击 + 动作 RPG + 魂系要素 |
| 多人 | 单人 / 最多三人线上合作，无 PVP、无分屏 |
| 定价 | 49.99 美元，三个 DLC 各 9.99 美元 |

前作《遗迹：灰烬重生》（2019）到 2021-12 累计超 300 万套，属于「没多少声量但活得不错」的中型作品。二代把体量和技术都往上抬了一档。

销量口径要分清：官方 2023-08-01 宣布首周四天破 100 万套；Embracer 2023-11 中期报告确认超 200 万套、当季净销售额超 7 亿瑞典克朗。Steam 同时在线峰值 110,856，是前作历史峰值的两倍以上。第三方估算（Gamalytic、GG Insights）Steam 约 260-340 万套，非官方数字。

## 核心设计：三层随机

这是本页最值得记的部分。遗迹2 的随机不是「生成一个世界」，而是三层不同粒度的抽签：

| 层 | 随机的对象 | 固定的是什么 |
| --- | --- | --- |
| 世界层 | 三个可随机世界（耶莎 / 洛斯曼 / 涅鲁德）的出场顺序；每个世界抽哪条主线 | 世界的数量、每个世界的主题与美术 |
| 场景层 | 每次跑固定 5 个地牢槽位——2 个 Boss 地牢 + 3 个支线地牢；地块拼接、敌人配置、注入事件 | 地块的形状模板、Boss 名单、地牢的准入条件 |
| 锚点层 | 不随机 | 每张图至少一个纯手工段落，其余部分围绕它生成 |

迷宫（Labyrinth）与根源地球（Root Earth）完全静态，是叙事锚点。三个 DLC 的开放世界也全部改成了静态，只随机地牢——这是有意的取舍，因为 DLC 要讲故事。

### 为什么这样切

对照 [[程序化生成]] 那页的结论：PCG 擅长造地形，不擅长造关卡，因为关卡的核心是节奏，而节奏需要作者意图，算法没有意图。

遗迹2 没有去解决这个难题，而是绕开了它。它的做法是把「关卡的节奏」交给手工地块，「关卡的排列」交给算法。玩家体验到的随机性来自「这次会碰上哪个」，而不是「这次地形长什么样」。

所以它有随机性但不显得廉价——因为每一块砖本身是设计的，随机的只是砖的顺序。

### 互斥种子：让 100% 完成在数学上不可能

每个世界在一次流程里只激活一条主线，其余主线锁死。加上支线地牢的槽位有限、注入事件每种每次流程只能出现一次、世界掉落的饰品每次流程每件只能捡一次，结果是：

**单次通关在结构上不可能看完全部内容。**

这是与「重复游玩」相关的关键设计。[[重复游玩价值]] 归纳了三种制造差异的方式：换玩法、换视角、换玩家自己。遗迹2 加上了第四种——换「这次遇到什么」。它不改变系统，不改变叙事视角，也不依赖玩家成长，它改变的是内容的可见性。

代价也很清楚：这种重复游玩的驱动力是 FOMO，不是理解加深。玩家第二遍不是为了「重新读懂」，而是为了「把没看到的补上」。所以它更接近收集而非重读。

## 双职业：有限叠加

职业（Archetype）是二代的另一根支柱。全 14 个：本体 11 个 + DLC 3 个。开局只能从四个里选（挑战者 / 驯兽师 / 猎人 / 医疗兵），枪手是预购奖励，其余靠解谜、任务、特殊条件解锁。

每个职业的结构是固定的：

- 1 个 Prime Perk（主 Perk，只有主职能吃到）
- 4 个 Perk（伤害 / 团队 / 功能 / 遗物）
- 3 个技能，分别在职业等级 0 / 5 / 10 解锁，同时只能挂一个
- 1 条职业特性（随等级自动成长，不消耗特性点）

双职业的规则设计得很克制：

| 规则 | 作用 |
| --- | --- |
| Prime Perk 只来自主职业 | 逼你选一个「身份」，不能全都要 |
| 副职业只给技能、Perk、职业特性 | 不给核心属性分点 |
| 经验在双职业间均分，满级职业不占份额 | 让「练新职业」不拖累主职业 |

第一条是最关键的一条。如果没有它，双职业会退化成「把 14 个 Prime Perk 全叠上」，平衡直接崩。有了它，组合从「加法」变成了「一个主基调 + 一个补丁」。

这和 [[装备等级与多样性]] 里那条结论同源：把复杂对象压缩成单一序数会消灭决策；但反过来，允许无限叠加同样会消灭决策。有限叠加才是决策成立的条件。

另外有一个值得记的补丁：最初副职业槽需要花 10 点特性点才解锁，后来（补丁 383,678）直接取消了这个前置——拿到第二个 Engram 就能装。同时职业解锁改成了账号通用：一个角色解锁后，其他角色花 1500 废料就能买到。这两条都是把「重复劳动」从系统里剔掉，属于典型的长线体验修正。

## 战斗：没有盾的魂

设计定位很清楚：没有盾牌格挡，只有翻滚闪避（带无敌帧）；没有主武器剑，主武器是枪。资源管理因此变成三条并行：

1. 体力条（冲刺与翻滚共用）
2. 弹药
3. 遗物充能（治疗）+ 技能冷却

这与传统魂系的单资源（体力）+ 缓慢回血结构不同。射击让玩家天然有远程输出窗口，翻滚让容错比魂系宽松，但 Boss 的攻击欲望和多段机制又把它拉回来。综合结果是「比魂系容易上手，但 Boss 依然要求读招」。

### Boss 设计

评测的共识是：二代 Boss 不再是「血厚的靶子」。它们的共同结构是：

- 多阶段 + 明确的读招窗口
- 弱点部位，且部分 Boss 的弱点选择本身构成解谜（立方体 Boss 要在被碾压的间隙判断下一个打哪个面）
- 场地机制参与战斗（而不是纯粹背景）

这一条与 [[动作游戏难度辅助]] 是互补的：那页讲的是如何让打不过的人过去；遗迹2 走的是另一条路——不加辅助，而是用三人合作和职业组合把「过不去」变成「换个 Build 再来」。

## 难度即收集路径

四档难度：幸存者 / 老兵 / 噩梦 / 天启。前三档开局可选，天启要通关一次才解锁。另有一个独立的硬核模式：角色死亡即永久消失，只能与硬核角色联机，全队团灭才算真死。

难度不只是数值倍率，它绑定了独占奖励：

| 难度 | 独占奖励（部分） |
| --- | --- |
| 幸存者 | 长老套、孢子喷发、铁铲 |
| 老兵 | 虚空套、救世主长枪 |
| 噩梦 | 光辉套、英雄之剑 |
| 天启 | Leto Mark 1 套、世界之刃、秘银遗物碎片 |

奖励可叠加上溯，通关高难度会同时拿到低难度奖励。判定标准是「在三个世界各击败一个世界 Boss，加迷宫哨兵和最终 Boss」。

这是一个把「难度」从体验选项改造成收集路径的做法。好处是给硬核玩家真实目标，不是纯炫耀；风险是大部分玩家永远不会看到这些内容，等于为 1% 的人做了 100% 的美术。

## 多人：不按水平分池，按人头调数值

[[多人游戏社交设计]] 那页的核心难题是：把不同水平的玩家塞进同一个匹配池，会产生双向流失螺旋。遗迹2 绕开了匹配这个环节——它根本没有随机匹配，只有好友/邀请制的三人合作。

它处理差异的方式是数值：

- 敌人血量与伤害随人数乘算
- 世界等级在玩家首次进入区域时按当前装备等级 +1 生成，且有下限（首世界与冒险模式 1-5，第二三世界 6-9，最终世界 12-14）
- Boss 有最低等级，防止被高装等玩家碾平

最后一条很关键。动态等级缩放的常见失败是「玩家练强了，内容变简单了，挑战消失」。给 Boss 设等级下限，等于承认「有些地方就该一直难」。

战利品在多人里是独立实例化：同一次拾取，每个成员各得一份；已拥有的物品自动转为制作材料。这个设计消除了「抢装备」这个社交摩擦源，同时也让分头探索成为可行策略。

## 商业层：没有通行证

这一层看似平淡，但对当前市场是个反例：

- 无战斗通行证、无赛季结构、无付费皮肤、无内购
- 三个 DLC 各 9.99 美元，明确承诺一年内出完，实际兑现（2023-11-14 / 2024-04-23 / 2024-09-24）
- 最终 DLC 同时免费更新了 Boss Rush 模式与棱镜（Prism）成长系统
- 发售后调低了洗点成本、取消了副职业的特性点门槛

PC Gamer 的评价可以引一句作为对照：在一个充满烦人微交易的市场里，一款「就是扎实」的游戏本身就有价值。

这条与 [[反商业化设计]] 是同一条线，但要看清它的前提：遗迹2 的定价是 49.99 而不是 69.99，团队规模是中型，销量目标不是千万级。**不做通行证的前提是成本结构允许它不做**，而不是道德选择。

## 检查清单

如果你要评估或设计一款「随机 + 魂系 + 合作」的游戏，按这几条过一遍：

- 随机的是「关卡排列」还是「关卡结构」？后者没有作者意图，会露馅。
- 每张图有没有一个手工锚点撑住节奏？全靠拼接的地图会缺少高潮。
- 单次流程能不能看完全部内容？能，则重复游玩要靠玩家自觉；不能，则要接受驱动力是收集而非理解。
- 多职业/多 Build 是加法还是有限叠加？没有「只能选一个」的核心位，平衡一定崩。
- 动态等级有没有下限？没有，则成长会吃掉挑战。
- 难度奖励是否独占？独占能造目标，也会让多数玩家看不到内容，要想清楚做给谁。
- 多人掉落是否独立实例化？共享掉落会引入社交摩擦，尤其在无匹配的合作模式里。
- 系列的重复劳动有没有被剔除（解锁是否账号通用、洗点是否便宜）？这类体验债会直接损耗长线口碑。

## 与相邻类型的边界

容易被归错类，先分清：

| 类型 | 遗迹2 的位置 |
| --- | --- |
| 撤离射击 / 搜打撤 | 不是。没有带入带出的装备损失，死亡只退回检查点，不掉东西 |
| Loot Shooter（无主之地、命运） | 不是。装备来自固定点位与 Boss 掉落，不靠随机词缀刷 |
| Roguelike | 不完全是。随机只作用于内容出现与否，不作用于单局构筑与死亡重置 |
| 魂系 | 是，但去掉了格挡与近战主导，加了远程输出窗口 |
| 刷宝 ARPG | 接近。核心循环是「拿新材料 → 做新武器/饰品 → 换 Build 打更难的 Boss」 |

最准确的描述是：**魂系的难度结构与 Boss 设计 + ARPG 的 Build 深度 + Roguelike 的内容随机化，三者拼在射击视角上。**

## 具体案例

### 洛斯曼的两种面貌

同一个世界，一次跑是哥特王城的宫廷阴谋（冒牌国王线），另一次是精神病院与血源风格的下城区（梦魇线）。地图名叫同一个，内容不是同一批。这是「世界层抽主线」最直观的效果。

### 立方体 Boss：弱点顺序即解谜

一个由方块组成的 Boss 在场地里滚动碾压，玩家要在躲闪间隙判断该打哪个面。它不是靠血量堆难度，而是把「读招」和「解题」合并成同一件事。

### 执政官（Archon）：把社区变成解谜的一部分

解锁条件需要特定装备组合加一个几乎不可能的路径，玩家社区靠数据挖掘才反推出完整步骤。这是把「秘密」做成元层面内容的极端案例——设计者预期玩家会协作破解。

### 三个 DLC 的静态转向

本体三个世界的开放世界是程序化的，三个 DLC 的开放世界全部改成静态手工。这个转向说明：当要讲故事时，随机性让位。随机适合「让你看不着」，不适合「让你看懂」。
