# 撤离射击 / 搜打撤

> 把「带装备进入、搜刮、活着撤离才算收益」做成核心循环的类型。它真正解决的是多人游戏的老问题：怎样让单局里的紧张感与长线的资产积累同时成立。

## 类型定义

撤离射击（国内常称「搜打撤」）的核心不是射击，而是一条风险规则：

**进入时携带的装备可以损失，撤离成功的战利品才真正属于你。**

这条规则把三个原本分离的东西扣在一起：

1. 单局的紧张感（一次失误可能损失全部携带物）
2. 长线的资产积累（成功撤离带来可累积的装备与经济优势）
3. 开放世界的自由度（路线、时机、交战与否都可以自己选）

传统多人射击解决了第 1 项，MMORPG 解决了第 2 项，开放世界解决了第 3 项。撤离射击的贡献是把三者拼成一个循环。

## 塔科夫：范式的奠基

necromanov 用「次世代爆款的第一组拼图」来形容塔科夫的位置。他的诊断起点是 2020 年前后三大超级品类同时陷进泥潭：MMORPG、多人对战、开放世界各自都有结构性问题。真正的问题不是「哪个更好玩」，而是有没有可能把三者的优点拼合起来。

塔科夫三年试错的结果就是「血赚」循环，四个部件：

| 部件 | 作用 |
| --- | --- |
| 强制匹配 | 保证单局必有其他玩家，风险真实存在 |
| 装备带入带出 | 建立损失与收益的对称性 |
| PK 爆装 | 让玩家之间的对抗产生实际经济后果 |
| 跳蚤市场估值 | 给所有物品一个可比较的价格，把「捡到东西」转成「赚了多少」 |

跳蚤市场这一环最容易被低估，但它是让循环闭合的关键：没有统一估值，战利品就只是收藏品；有了估值，每一次搜索都变成一次决策。

## 撤离射击的真正难点：三类玩家的匹配冲突

类型成立之后，问题转移到人口结构上。necromanov 在分析 Arc Raiders 时把这个问题拆得比较清楚。

PVP 和 PVE 玩家的流失各有各的螺旋：

**PVP 流失螺旋**：不合理挫败感 → 轻度玩家流失 → 中等玩家匹配压力增大 → 再流失 → 雪崩。

**PVE 流失螺旋**：高难副本排斥新手（「卡拉赞没毕业打什么卡拉赞」）→ 策划降低难度 → 反而降低普通玩家的提升动力 → 内容消费过快 → 又需要加难度。

两条螺旋的共同点是：都源于把不同水平的玩家塞进同一个匹配池。欧美多人游戏多以每月接近腰斩的比例卷走留存，问题不在内容量。

### Arc Raiders 的解法：行为记录匹配

Arc Raiders 的做法是不按水平分池，而按行为分池：做好人匹配好人，做坏人匹配 PVP 对手，从而造出一个稳定的「灰色」第三类体验——敌友不定、信息不定。

这个解法跳出的是「难度分层」的传统思路。它承认一件事：玩家要的不只是合适的难度，还有合适的社交环境。把「善意玩家」和「掠夺玩家」分开匹配，两类人都能得到自己想要的单局。

配套的数值调整也值得记：为了强化灰色体验，击杀时间（TTK）拉长、主要武器交战距离缩短，用这两条压制 PVP 的压倒性优势，让「不打」成为可行选择。

### 一个关键判断

留存难题不是内容不足，而是规则没有给不同水平和倾向的玩家各得其所的入口。重构匹配规则比堆内容更根本。这条判断不只适用于撤离射击，是整个多人游戏领域的通用结论。

## 设计要素清单

如果你要评估或设计一个撤离射击，按这几条过一遍：

- 进入成本是否可承受？新手带一身便宜装备进场也该有活路，否则前 10 局全是劝退。
- 撤离点设计是否制造决策？固定撤离点会让路线固化，随机或多撤离点才产生「再搜一次还是现在走」的张力。
- 战利品是否有统一估值？没有价格体系，搜刮就失去比较基准。
- 是否给「不交战」留出空间？纯 PVP 会赶走大部分受众，灰色地带才是这个类型的人口基本盘。
- 匹配是按水平还是按行为？按水平只能解决难度，按行为才能解决社交环境。
- 长线是否有除装备以外的目标？纯装备积累会随赛季清零而失去意义。

## 与相邻类型的边界

容易混淆的几个类型，判据是「死亡时损失什么」：

| 类型 | 死亡损失 | 核心张力 |
| --- | --- | --- |
| 撤离射击 | 携带的全部装备 + 本局战利品 | 贪婪与保全的权衡 |
| 大逃杀 | 本局进度，装备不跨局 | 活到最后 |
| Roguelike | 本局进度，meta 成长保留 | 每次重来的构筑差异 |
| MMORPG | 少量修理费或经验惩罚 | 长期角色养成 |

撤离射击的独特点是它把「损失」本身做成了核心乐趣的来源。玩家不是为了避免损失而玩，是因为有损失才觉得搜到的东西值钱。

## 具体案例

### 塔科夫：三个类型的缝合实验

MMO 的经济长线 + 单局的紧张刺激 + 开放世界的自由路线。三年迭代才把循环跑通，说明类型融合的难度不在想法而在调参。

### Arc Raiders：用行为匹配造灰色地带

不按技术分池而按行为分池，让善意玩家与掠夺玩家各自得到合适的环境。TTK 拉长、交战距离缩短，让「不打」成为可行策略。这是本类型在匹配层面的重要突破。

### 三角洲行动：搜打撤的重构尝试

GDC25 的分享主题是「成为英雄，重构搜打撤玩法」。国内厂商在这个类型上的做法是把英雄技能体系叠进去，用角色差异弥补纯枪法分层的粗暴。这条路是否成立还需要更多样本。
