# 02-知识库/对比（对比分析页）

## 目的
把同类可比较对象并置对比，提炼共识与分歧。通常由多份 `02-知识库/素材/` 综合而成。

## 给 AI Agent

### 在此目录工作
- 命名：`{对比主题}.md`。
- **front-matter**：`tags`（含「对比」+ 相关标签）/ `created` / `updated` / `sources`（并置的素材列表）。
- 用表格做「一句话对比」，再逐条详解；标注共识与分歧。
- 关系类型用 `06-手册/知识库规范.md` 的关系类型词汇表：实现 / 依赖 / 对比 / 矛盾 / 衍生。
- 对比结论中涉及的高风险事实先核验（`03-核验/`）。

### 校验要求
- 对比对象是否都有对应 `02-知识库/素材/` 或 `02-知识库/概念/` 支撑。
- 标注的「矛盾」关系是否确实存在观点冲突。

### 常见模式
- 一句话对比表（路线 / 代表 / 核心主张 / 落地场景）+ 三条路线详解 + 共识与分歧。

## 依赖

### 内部
- 上游：`02-知识库/素材/`（并置素材）、`02-知识库/概念/`（对比对象）。
- 下游：`02-知识库/主题/`（对比结论回写主题页）、`总索引.md`。
