# 游戏设计

> 游戏设计支柱(C 支柱)的总入口:可复用的设计框架、制作约束与产品判断方法。素材来自三条线——**经典理论层**(英文原始文献,MDA/Schell/Salen & Zimmerman/Juul 等,讲"框架从哪来")、**GDC/GMTK 讲座译制**(611 篇,工业方法论,讲"怎么做")和 **[[旗舰评论]] necromanov 文章**(67 篇,18 年深度评论,讲"为什么好/坏")。

## 经典理论层(英文原始文献)

两条中文线讲的是"业内怎么做",这一层补的是"框架本身怎么来的"。整套谱系、阅读顺序与理论总图见 [[游戏设计理论谱系]],下表按「回答什么问题」分组:

| 回答什么 | 理论 | 原始出处 |
|---|---|---|
| 游戏是什么 | [[古典游戏模型]] / [[游戏定义]] / [[魔法圈]] / [[有意义游玩]] | Juul 2003;Huizinga 1938;Salen & Zimmerman 2004 |
| 体验从哪来 | [[MDA框架]] / [[元素四元组]] / [[设计镜头]] | Hunicke-LeBlanc-Zubek 2004;Schell 2008 |
| 为什么好玩 | [[游戏之心]] / [[技能原子]] / [[心流]] / [[四把钥匙]] | Koster 2004;Cook 2007;Csikszentmihalyi 1990;Lazzaro 2004 |
| 玩家为什么留下 | [[玩家类型]] / [[自我决定理论]] / [[八角行为分析]] / [[玩家旅程]] / [[循环与弧线]] | Bartle 1996;Deci-Ryan;Chou 2015;Kim 2000;Koster 2012 |
| 规则能说什么 | [[叙事建筑]] / [[环境叙事]] / [[游戏性叙事失调]] / [[程序修辞]] / [[游戏学与叙事学之争]] | Jenkins 2004;Hocking 2007;Bogost 2007 |
| 结构可复用 | [[游戏设计模式]] / [[难度曲线]] / [[游戏奖励设计]] | Björk & Holopainen 2005 |
| 院校怎么教 | [[USC游戏设计方法]] / [[CMU娱乐技术中心]] / [[NYU游戏中心]] | Fullerton 2004;Pausch 1998;Lantz 2008 |
| 认知怎么承载 | [[SRK框架]] | Rasmussen 1983 |
| 业界怎么说 | [[业界设计信条]] / [[Cerny方法]] / [[OODA循环]] / [[引擎与经济]] | Meier 2012;Cerny 2002;Boyd 1987;Sylvester 2013 |

一个使用提醒:这些理论多数不是实证科学,而是被行业反复使用的思考工具。每页都标注了原始出处与主要批评,读时不要跳过批评部分。

更要注意:上面这些框架之间并不互相承认。三所顶级院校教的东西互不兼容,产业界的格言彼此矛盾——为什么,见 [[游戏设计流派与争论]]。

## necromanov 旗舰评论(67 篇深度评论)

[[旗舰评论]] 是 necromanov 18 年的游戏设计评论集,每篇是对具体游戏的深度拆解。按主题分布见上方子主题页;完整清单见 [[01-原始素材/旗舰评论/索引|necromanov 总索引]]。

核心价值:与 GDC 的"工业方法论"互补——GDC 讲"怎么做",necromanov 讲"为什么好/坏",两者交叉阅读效果最佳。
