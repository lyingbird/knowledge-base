# 系统与策略设计

> 系统驱动游戏的随机性、平衡与涌现,策略游戏的设计方法论。本主题串起 [[旗舰评论]] necromanov 18 年案例链:从大帝国"无随机纯人力挑战"到 POE"受控随机性",从文明"决策+反馈"神韵到塔科夫"血赚"循环与 Arc Raiders"灰色单局",追问策略深度的真正来源——以及平衡性、复杂度、留存螺旋这些系统性难题如何破解。

## 核心判断

以下判断综合 [[旗舰评论]] necromanov 系列多篇评论提炼,非单一文章结论。

### 一、平衡性是不可计算的幻象,设计师真正该做的是"修正明显失败的设计"与"为引导玩家行为而再平衡";追求"无懈可击"反而扼杀设计锋芒

[[necromanov_游戏数值设计2平衡性问题]] 给出纲领:平衡性的两种定义(足够简单到看不出不平衡/足够复杂到不能很快找到不平衡)都无操作性——连围棋先手贴目各地都无共识,不可能用数学+用户反馈给庞大游戏算出平衡性,"那个平衡性只是幻像"。承认之后真正该做两件事:①修正"明显失败的设计"(玩家脱口而出"这不公平"的东西);②"再平衡"——不为修紧迫问题,而是为引导玩家行为(如全治疗牧师已平衡但加修正可开辟"盾牧师"新玩法)。凡借平衡性之名说不清原因的改动都是"罪恶"。这条判断在 [[necromanov_星际争霸2无懈可击的平庸]] 以反面形式验证:暴雪从"大胆改进+锐利实现"转向"没有缺陷+无懈可击",对战兵种回到星际1时代——追求无懈可击恰恰让星际2"锋芒已逝",沦为平庸之作。

### 二、随机性是一条设计谱系而非好坏二分,关键看它服务于决策深度还是戏剧性产出

[[necromanov_影子旗舰卢比扬卡没有随机性的世界大帝国]] 是谱系一极:大帝国剔除所有随机性(计算正确就无损),用纯粹人力手填针对性数值挑战,是"战略游戏数值设计教科书"——证明复杂度不必依赖随机。谱系中段是 [[necromanov_重返流放之路受控随机性与策略深度]] 的 POE:不是去掉随机,而是给玩家"控制随机性的工具"(货币可刷地图/箱子/BOSS掉率),把控制随机性本身变成奋斗目标,成为策略深度支柱;对比魔兽装等系统用统一数值排序牺牲多样性。谱系另一极是 [[necromanov_钢铁雄心4构造戏剧性]] 的反历史影响力系统:意识形态传播/革命/内战是系统生成的不可预测性,服务于直播时代的戏剧性产出。失败案例则是 [[necromanov_群星Stellaris当文明遇到历史逻辑]] 指出的群星科技全库加权随机("看脸风云")——随机减少了决策成分,不像文明需规划冲击核心科技的远景。判断:好的随机要么可被玩家控制(POE),要么可被系统复算(大帝国),要么服务于戏剧性而非替代决策(HOI4)。

### 三、策略游戏的核心是"决策密度×决策重要性×反馈清晰度",后期乏味是系统性难题,解法是把后期重新决策化

[[necromanov_群星Stellaris当文明遇到历史逻辑]] 剖析4X的"再来一回合"神韵不在四词定义(探索/扩张/开发/征服),而在"决策+决策结果反馈"——有限、令玩家感到重要的决策;文明高手是能在细微决策中找最优估值的人。但文明后期是垃圾时间:30城时造什么单位已无估值必要,正反馈循环使电脑难翻盘。群星用维多利亚式事件逻辑(人口随科技/帝国扩大分化触发连锁事件)把后期重新决策化。[[necromanov_时隔二十年的复活从UFO到新XCOM2]] 给出战略层另一解法:XCOM1可无限拖时间(高难度下拖时间收益超过赶进度),XCOM2引入"电脑发展曲线"——给不同难度电脑设定发展速率,玩家必须规划核心小队成长以跟上。但 [[necromanov_老革命遇到新问题席德的文明世界|CivWorld]] 提供复杂度的反警示:系统过于复杂(回报靠调整建筑物距离+相邻关系),60%完不成教学、仅10%学会玩法,产出仅设计预期1/10——没有学习曲线支撑的复杂系统会自我失效。

### 四、多人/单局系统的留存难题根植于"匹配人口结构",解法是重构单局规则而非堆内容

[[necromanov_逃离塔科夫次世代爆款的第一组拼图]] 诊断:2020年三大超级品类(MMORPG/多人对战/开放世界)皆陷泥潭,核心问题是有可能拼合三者优点吗?塔科夫三年试错找到"血赚"循环——强制匹配+装备带入带出+PK爆装+跳蚤市场估值,融合MMO经济长线、单局刺激、开放世界自由度,是次世代爆款第一组拼图。[[necromanov_灰色单局玩法pve和pvp之外的另一类可能性]] 进一步诊断"流失死亡螺旋":PVP流失(不合理挫败感→轻度流失→中等玩家匹配压力增大→雪崩)与PVE流失("卡拉赞没毕业打什么卡拉赞"——高难副本排斥新手→策划降难度→反降普通玩家提升动力)各自制造螺旋,欧美多人游戏多以每月近腰斩比例卷走留存。Arc Raiders的解法是"玩家行为记录匹配"——做好人匹配好人、做坏人匹配PVP对手,创造稳定"灰色"第三类体验(敌友不定/信息不定),跳出死亡螺旋。判断:留存难题不是内容不足,而是规则未给不同水平/倾向玩家各得其所的入口;重构匹配规则比堆内容更根本。
