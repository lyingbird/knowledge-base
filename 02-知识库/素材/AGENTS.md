## 给 AI Agent

### 在此目录工作
- 命名：`{日期}-{短标题}.md` 或 `{短标题}.md`（项目学习页用项目中文短名）。
- **front-matter**：`tags`（含「素材摘要」+ 主题标签）/ `created` / `updated` / `sources`（链回 `01-原始素材/` 原始素材或 `01-原始素材/视频笔记/...`）。
- 结构：来源 → 核心观点 → 可复用概念 → 待核验点 → 相关页面。项目学习页用 `06-手册/知识库规范.md` 的「项目学习页结构」。
- **必须链到 entities/topics**，否则就是「素材孤岛」（Lint 检查项）。
- 区分原始演讲/来源与 B 站二次讲解、主持人扩展、外部案例，写清归因边界。
- 高保真视频摘要：不压成泛泛摘要，保留章节、例子、数字、人名/公司/产品名、术语、推理链、ASR 疑点。

### 校验要求（Lint）
- **素材孤岛**：只链原文、不链任何实体/主题的摘要页。
- 摘要中的高风险事实是否分流到 `03-核验/待核验事实.md`。
- `01-原始素材/视频笔记/` 每篇是否都有对应摘要（近期维护重点）。

### 常见模式
- 摘要页用 `sources: [01-原始素材/视频笔记/...]` 或 `[01-原始素材/...]` 反向链回原始素材。
- 「可复用概念」节用 ``实体名`` 链到实体页。
