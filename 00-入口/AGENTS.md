# 00-入口（人类阅读入口）

## 目的
只放导航。这里的东西应该能让人在两分钟内找到方向，不放规范、流程、SOP、清单。

判断标准：一个文件如果是在回答"我该读什么"，它属于这里；如果是在回答"我该怎么写/怎么做"，它属于 `06-手册/`。

## 关键文件

| 文件 | 说明 |
|------|------|
| `首页.md` | 唯一入口，四条主线的分发点 |
| `游戏设计MOC.md` | 游戏设计地图：按问题查、按理论层查 |
| `AI组织MOC.md` | AI 与组织地图 |
| `技术学习MOC.md` | 技术学习路线地图 |
| `独立开发MOC.md` | 独立开发地图 |

## 子目录
无。入口层保持扁平，不再分层。

## 给 AI Agent

### 在此目录工作
- 只新增导航页或更新已有 MOC，不在这里写正文知识。
- 新的结构化知识写进 `02-知识库/`，规范与流程写进 `06-手册/`。
- 新增 MOC 后，必须在 `首页.md` 的四条主线表里登记，否则没人能找到它。

### 校验要求
- 入口链接必须指向真实存在的页面（避免断链）。
- MOC 里的每条链接都要能点开，新增理论页后回补对应 MOC。

### 常见模式
- 用 front-matter `tags` 标注「首页」「MOC」「导航」。
- MOC 用「按问题查」表格开头：左边症状、中间框架、右边案例。

## 依赖

### 内部
- `首页.md` 与仓库根 `总索引.md` 互为入口（`总索引.md` 是全量清单，MOC 是阅读路径）。
- 规范与流程全部在 `06-手册/`，本目录不再持有副本。
