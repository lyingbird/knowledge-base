# 阿里Qoder叔同谈AI Coding战场（十字路口）

> 阿里 Qoder 创始人叔同（前双 11 技术负责人）谈全球 AI Coding 战场。核心差异化：面向**真实软件**（95%+ 开发者在维护存量商业代码,而非创意 web 新品);上下文工程是核心壁垒;AI Coding 有自家模型才不是「套壳」;上线 2 个月 50 万活跃开发者。

## 核心内容

归因边界:创始人对赛道与自家产品的判断;用户数/竞品营收为口播,需核验。

### 核心论点

1. **AI Coding 三层分化**:0→1(web 创意,如 Claude Code)、1→10(专业工具链,如 Cursor)、10→100(企业级替代);最终大一统,内核是「通过编程提供软件服务」。
2. **差异化切口:面向真实软件**。95%+ 专业开发者维护已存在的商业软件而非创意新品;多数竞品聚焦低价值 web 创意,Qoder 攻占价值高地——**存量代码维护**。
3. **模型对产品的制约**:无自家模型=「套壳」(成本高、无法端到端优化、利润被模型方吃);预判 Cursor 必做自家模型。
4. **开发效能三阶段**:辅助(autocomplete)→协同(pair programming)→**自主编程**(agent 全自主);Qoder 定位下一代自主编程平台。
5. **上下文工程是核心壁垒**:性能/效率/成本不可能三角,谁更会构建上下文(语义检索、记忆、agent 协同)谁赢。
6. **全球最优模型集成 + 机选优于人选**:不让用户选模型(内部按场景自动选),「平台知识优于个人知识」;自家模型储备,若变最优可快速切换。

### 关键概念

- **RepoWiki**:AI 自动生成并持续更新的代码库文档(基于提交记录/架构分析),初版 60 分钟→最新 12 分钟(缩短 5 倍)。
- **SPAC 驱动**:结构化需求文档(业务逻辑/技术选择/模块设计/验收标准)驱动 agent 长期自主编程。
- **Quest Mode**:自主编程模式,用户定义 TODO List,agent 按序执行、支持中途询问调整——Agent Harness 的产品化实现。
- **云端沙箱**:10 个异步并行沙箱,agent 离线长期工作(不受用户工作时间限制),「1 人带 10 个 agent」10 倍生产力。
- Qoder:上线 5 天破 10 万用户、2 个月 50 万活跃开发者;Day 1 全球化一套产品。
