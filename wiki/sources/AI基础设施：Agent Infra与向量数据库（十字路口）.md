# AI基础设施：Agent Infra与向量数据库（十字路口）

> 两期十字路口对谈拼出 AI 基础设施层：小宿科技（Agent 的搜索/模型聚合 PaaS，2500 万美元 ARR）与 Zilliz（向量数据库，6 亿美金估值）。核心：Agent 时代搜索从「人对机器」变「机器对机器」；向量数据库是 Agent 的长期记忆层；开源是基础设施的护城河而非捷径。

## 核心内容

归因边界：创始人对自家赛道的判断；ARR/估值/融资/节点数为口播，需核验。

### 小宿科技（Agent Infra，杜知恒）

- **「Agent 元年第一天早上 6:05」**：头部 Agent 用户规模不到移动互联网成熟期 1%，市场还有 100 倍成长空间。
- **搜索从 C 端转向 B 端**：Agent 时代变「机器对机器」搜索，2B 搜索占比可能从 5% 升至 80-90%。
- **Bing Search API 退场是关键信号**：微软 2 月停对中国模型厂 API、8 月全球 retire，推动中国团队自研搜索。
- **产品**：小宿智能搜索（为 Agent 优化的搜索 API：实时/全文/多模态/多语言/合规）+ SkyRouter.ai（全球大模型 API 聚合）。为 1-5 人小团队提供「Day 1 就像大厂」的 PaaS。
- **PaaS 层竞争替代 IaaS**：从抢卡转向抢数据和一站式服务；头部模型厂只自建占 90% 流量的头部查询，长尾 10% 需第三方补齐。
- 2026-06 ARR 超 2500 万美元、已 break even、100+ 人（70% 研发）。CEO 杜知恒（清华、前红杉二级基金一号员工）。

### Zilliz（向量数据库，星爵）

- **向量是神经网络的基本数据单位**，AI 时代需求激增；向量数据库是 [[智能体]] 的**长期记忆层**（不只单个 RAG，还有多租户/实时更新/大规模管理）。
- **开源是护城河而非捷径**：低成本进开发者心智、获反馈循环、驱动迭代；学 Databricks「对偶模式」（开源+商业版并行，商业版永远领先开源 12-18 个月）。
- **基础设施是「苦」赛道**：没有一夜暴富，只有每天复利叠加，需极强耐心。
- 「工程师 CEO 从纯理想主义→灰色现实主义，但内心保留彩色理想主义一角」；「你比对手好一些就够了，不用好太多」。
- 产品 Milvus（开源）+ Zilliz Cloud；约 130 人/8 年；2023 GTC 被黄仁勋点名，营收增长 3.3 倍。

## 对知识库的价值

- **Agent 基础设施层**：补强 [[Agent Harness]]、[[OpenClaw]] 主线——Agent 执行需要的搜索/模型/记忆基建；「记忆层=向量数据库」与库内「记忆>智能」（[[游戏AI NPC两路线对比]]、Hermes 多层记忆）呼应。
- **与 [[Agent前沿三人谈：Harness三层-人机协作-主动式AI（十字路口）]] 对接**：Harness 三层的「执行层/状态层」正需要这类 infra；「机器对机器搜索」呼应主动式 AI 的 context 获取。
