### 核心论点

1. **分界点是 OpenClaw**：一月看只当 UI 创新，春节深度使用后认为它「改变了整个人-模型交互范式」，是划时代的 Agent 框架。
2. **Agent 框架能极大弥补模型短板**：较小模型 + 高质量 Agent 框架，在多数场景能接近顶尖模型（如 Claude Opus 4.6）。
3. **卡的分配 3:1:1**：研究(3) : Pre-train(1) : Post-train(1)——Pre 与 Post 投入应相当。
4. **Agent 范式吃 Post-train**：Agent 框架定义一套「执行规范」，这种规范在预训练数据里没有（多是组织内部积累），只能靠人-Agent 多轮交互完成任务来习得——Post-train 是核心承载。
5. **研究效率质变**：想法→代码→评估从 1-2 周加速到 1-2 小时，从串行验证变并行验证多个想法。
6. **Code 拿上限、其他场景保下限**：长程任务建模能力对泛化至关重要。
7. **群体智能加速**：一百多人在同一框架协作改进，框架数小时的迭代等于单人数周；这是 OpenClaw 开源的核心价值。
8. **模型与框架双向演进**：顶尖模型须与顶尖 Agent 框架同步进步，框架对 memory（静态）与 workflow（动态）的编排要随训练变化。
9. **开源的必要**：闭黑盒框架无法被社区洞察改进，开源激发大规模创造力。
10. **成本是生产力革命的前置**：不追最高能力而追「成本-效率」最优，「10 块钱 API 干 1000 块钱的事」才是触发点。

### OpenClaw 超预期之处

「惊喜编排」（感知时间的上下文拼接）、持久分层记忆、多模型联合利用（自动调更合适的模型）、自主任务调度（心跳）、可被用户自定义修改内部架构。

### 巨变下的组织（团队实践）

春节体验记：第一天投入近 1000 美金用 Claude Opus 4.6，觉框架有「灵魂」；第二天做非代码任务（哲学讨论、组织设计），当「数字分身」；第三天把研究任务交给它，数天工作 1-2 小时完成。之后团队拉多个 OpenClaw 群、下「对话不足 100 轮」的态度指令、进入躁动式协作——组织从「串行/个人」转向「并行/集体」。
