# 【中配】用AI制作罗布乐思爆款游戏 其实很简单 - tef

> 核心观点：一个不会写 Luau 的 YouTuber 用 [[Claude Code]] + [[Rojo]]，按"里程碑式"vibe coding 流程，约 2 小时做出一款可玩的 Roblox 盗匪刷宝升级游戏原型《Bandit / 盗匪克星》。开发者只描述需求与反馈，代码全交给 AI。

## 核心判断

这条素材是 [[AI辅助游戏开发]] 主题里**完整度最高的项目级样本**：不是做一个小功能，而是从零搭一款有经验/倍率/战斗/任务/分区/属性系统的 RPG 刷宝游戏原型，并演示了一套可复用的"里程碑式 vibe coding"工作法。它把 [[Claude Code]] 从"改单个脚本"推进到"扛起整款游戏的代码与系统搭建"。

## 项目设定

- 游戏名《Bandit / 盗匪克星》，灵感来自 Blox Fruits，属"刷盗匪升级"类（真刀真枪打盗匪 + 角色升级，类 RPG 但耐玩）。
- 两种流派：剑术 / 徒手近战。属性与经验值参考 Roblox 已有 RPG。
- 核心机制：击败盗匪/完成任务累计**倍率**，每次命中经验按倍率加成（例：第一个任务 +0.1 倍率，更难任务 +0.5 倍率）——"打得越多刷级越轻松"，作者称这是核心卖点。
- 本期目标：做出可玩原型，后续围绕它建玩家社区、正式发布、做系列视频。

## 工具链

- **[[Claude Code]]**：作者称是"目前做游戏最强的工具，也是除已停服的 Fable 5 之外市面最好的编程 AI"（**主观评价 + Fable 5 待核验**）；用了 Ultra/Ultrathink 模式。
- **[[Rojo]]**：同步客户端，把本地文件自动同步进 Roblox Studio，免去手动复制粘贴代码（"光配置同步权限就报错了好几次"）。

## 里程碑式开发流程（精读）

把整款游戏拆成里程碑，每个里程碑给 Claude 一段需求，做完即时进游戏测试、用"玩家/策划"口吻反馈再迭代：

- **里程碑 1（底层框架）**：Claude 先写好核心经验值 + 倍率系统的底层框架和服务器端逻辑。
- **里程碑 2（战斗系统）**：盗匪 NPC、剑术与近战流派、每次命中变强机制。初版剑像棍子、无攻击动画、NPC 是方块且会主动打人；逐条反馈让 Claude 改成"培根头"人形 NPC + 武士刀模型 + 攻击动画 + Q 键冲刺 + 连击 + 提高点击攻速。
- **里程碑 3（任务系统）**：可走近对话的任务 NPC、接"击杀若干盗匪"任务。修复"任务进度不统计"、把任务 NPC 移出战斗区、改盗匪为**被动**（玩家先攻击才反击，否则不追），任务 UI 移到左侧，主菜单含属性/地图/任务/商店按钮；任务进度实时更新、完成给倍率奖励。
- **里程碑 4（世界分层 + 属性）**：村庄郊外 / 商路 / 盗匪山区域，盗匪新手/壮汉/队长对应不同等级段；属性加点（加力量+防御后每击约 30 伤害，体验明显变好）。世界地图摆放仍需作者**手动**搭。

## 结论与边界

- 成果：约 2 小时做出可玩原型，作者认为"对独立开发者已经很不错"。
- 遇到 **Claude 使用额度限制**（用量上限），里程碑 4 后基本停手。
- 仍需人工的部分：世界场景摆放、挑选/微调模型、判断 Claude 是否"骗人"（"有时候 Claude 会骗我，要实际测试"）。
- 工作法可复用性：清晰的里程碑切分 + 即时游玩测试 + 以"产品/策划反馈"驱动迭代，是这类 vibe coding 做游戏的关键。
