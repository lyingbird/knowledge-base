## 核心内容

归因边界：创业者在浪潮顶峰的展望与信念，多为「即将发生」的规划；用户数/融资/发布时间等需核验。

### 核心论点

1. **产品演进规律**：AI 应用从填表单（Jasper）→ 对话（ChatGPT）→ 带上下文（Monica/豆包）→ 代码执行（Cursor）→ Agent，每次演进更贴合普通人习惯、能力更强。
2. **「新安迪-比尔定律」**：模型能力按摩尔定律进化，应用「壳」需同步进化，第三方应用把模型能力的用户价值呈现出来。
3. **模型会商品化**：长期看模型趋向商品化，竞争最终靠应用而非模型。DeepSeek（开源、低价、体验好）证明了这点，给应用公司信心。
4. **应用与模型非零和**：不必二选一，互补；原厂顾不上的领域（特定行业、繁琐任务、有窗口期的产品）是应用公司机会。
5. **真正的 Agent**：不仅会聊天，还自己写代码、调 API、用工具；是像 iPhone 的通用架构，而非功能机（feature phone）式 feature 堆砌——这正是 Monica 曾经的问题。
6. **创业心态**：保持乐观、做自己相信的事，不被「失心（执着顺境）/嗔心（不满逆境）」困扰，让自己成为博弈中的重要变量。
7. **技术窗口**：预判下一步能力、提前做产品，能力到来即爆发，不能等看到结果再做。

### Manus 是什么

通用**消费级** Agent（非工程师向）：虚拟机 + 浏览器 + 代码执行 + API 调用，自主拆解任务、多轮迭代、支持异步长任务与中途改需求。爆火因模型能力（Claude 3.5 Sonnet 的 Agentic 能力）恰好 ready + DeepSeek 的启发 + 对标 Cursor 的通用化。定位对标 Monica 的进化，不走 Cursor/Devin 垂直路线。

### 肖弘

2015 年大四创业；2017 起做 Monica（ChatGPT API 浏览器插件，用户量大但陷「功能机」问题）；2023 提出 context-aware chatbot 被大厂快速跟进（豆包）；2024 思考 Agent，春节前立项 Manus。
