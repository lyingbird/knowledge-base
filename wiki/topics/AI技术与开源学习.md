# AI技术与开源学习

> 知识库的「技术/学习支柱」总入口：把值得掌握的 AI 技术、工程实践与开源项目，从「收藏链接」沉淀为「能讲清方法、能动手复现」的学习页。

## 核心内容

这是与「AI 组织/产品/治理」并列的第二条支柱（见 [[purpose]]）。它收的是 GitHub 仓库、论文、技术文档这类素材，目标是**深入学习**而非泛泛收藏。每份素材按 `.wiki-schema.md` 的「GitHub / 开源项目学习素材 Ingest 规范」处理：raw 副本 → source 学习页（含动手清单）→ 抽取实体 → 归入主题。

按内容大致分两类：

- **研究/技术项目**：理解某个方法怎么工作、能否复现。例：[[see-through动漫单图图层分解]]（[[图层分解]] + [[扩散模型]]）。
- **方法论/工程实践**：可复用的工作方式与准则。例：[[Karpathy编码原则与Claude-Code-Skills]]（[[LLM编码原则]]）。

系列作者的成体系作品单独建学习路线，逐个深入：[[Karpathy开源学习路线]]。
