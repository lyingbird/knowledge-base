# 独立开发与微型SaaS

> 单人或极小团队，用低成本、可复制、可自动化的方式做「小而赚钱」的 SaaS：选题靠复制已验证产品，验证靠公开数据与广告，增长靠 SEO / 自动内容 / 联盟营销的渠道叠加。

## 主题定位

这条主题关注「indie hacker / solopreneur / micro-SaaS」视角：不追求超级入口、巨额融资或基础模型，而是把个人精力、成本结构和失败率当作首要约束，用工程化、自动化的方式让一个人也能跑通「选题 → 验证 → 构建 → 增长 → 盈利」的闭环。

它与 [[AI创业与投资]] 是对照关系：后者是 VC / 大资本视角（应用入口、私有化部署、硬件闭环、基础模型牵引），本主题是「小团队、低成本、复制已验证产品」的反向视角。AI 编码工具让「一个人造 90% 的应用」成为前提，是这条主题在 AI 时代成立的技术基础。

## 核心方法链（来自当前素材）

1. 选题：[[克隆并改进1%]] + 四大筛选条件（自己会用 / 已上线 / 没烧大钱营销即有真实需求 / 简单易维护）。
2. 验证：[[公开构建]] 社群里的 MRR / [[Stripe]] 截图当作免费市场调研；流量来源（广告 vs SEO）= 可复制性的代理指标。
3. 构建：两周 MVP，跳过无聊功能（密码重置、设置页），技术栈 [[Next.js]] + [[Node.js]] + [[Vercel]] + [[Stripe]]。
4. 增长四步：广告（最快验证）→ [[程序化SEO]]（复合免费流量）→ [[无脸视频内容]] 自动频道（自有自动化分发）→ 联盟营销（固定成本 + 病毒传播 + 内容多样性）。
5. 成本意识：依赖服务器/实例自动化的产品边际成本高、容量受限，直接影响利润。
