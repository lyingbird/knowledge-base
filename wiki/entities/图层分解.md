# 图层分解

> 把一张「拍平」的单层图像还原成语义独立、被遮挡区域补绘完整、且带绘制顺序的多个图层，从而让静态图变得可编辑、可动。

## 核心内容

图层分解（layer decomposition）解决的是「单张图里信息被遮挡、被压平」的问题。一张成品图上，前景盖住背景、头发盖住脸，被遮挡部分没有像素。要让图可编辑（换表情、转头、做 2.5D / Live2D、替换元素），就要拆回三件东西：

1. **分割**：哪些像素属于哪个语义部件（[[扩散模型]] 之外常用 SAM 系分割）。
2. **补绘（inpainting）**：把每个图层被遮挡、原图不存在的部分补全，通常输出带 alpha 的透明图层。
3. **排序**：推断图层前后顺序（常借助深度估计）。

[[see-through动漫单图图层分解]] 是一个完整实现：SAM 分割 + LayerDiff 3D 透明图层生成 + Marigold 深度排序 → 导出 PSD。该范式不限动漫，可迁移到任何「单图 → 可操作分层」的任务，是把生成模型嵌入 [[游戏生产管线]] 和 [[3D生成]] 的关键能力之一。
