# 公开构建

> build in public：独立开发者在 Twitter/X 等公开渠道实时分享产品进展、收入（MRR）和 Stripe 截图。对外是营销和获客，对旁观者则成了一座免费的「已验证需求」情报库。

## 核心内容

[[Samuel Rondot]] 把围绕 solopreneur / indie hacker / build in public 的 Twitter 社群当作主要创意来源（[[我克隆了3个成功App，现在月入3.5万美元]]）。公开构建文化的副作用是：创始人主动晒出的 MRR 截图、[[Stripe]] 截图、获客方式，成了外部观察者判断「这个产品是否被验证、需求是否真实、是否值得克隆」的免费数据。

这正是 [[克隆并改进1%]] 方法成立的信息基础——没有 build in public，旁观者无法低成本地拿到「谁在赚钱、靠什么获客」。

## 双重作用

- 对发布者：建立信任、吸引早期用户、招联盟伙伴、形成个人品牌。
- 对观察者：免费市场调研，定位已被验证的可复制标的。
