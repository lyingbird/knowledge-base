# 产品品味

> 产品品味是在实现成本下降后，仍能判断该做什么、怎样做才对、什么体验会让用户真正获得价值的能力。

## 核心内容

Cat Wu 在 [[Anthropic产品负责人：AI时代，产品经理最值钱的能力是品味]] 中提出：代码越来越便宜后，真正变贵的是“决定写什么”。Claude Code 有成千上万 GitHub issues，用户会要求几乎所有功能；团队必须判断哪些值得做、怎样做、正确 UX 是什么、用户什么时候会感到 delight。

产品品味不是审美词，而是优先级判断、用户路径判断、技术成本判断和组织节奏判断的组合。

## 在 AI-native 产品中的表现

- 判断当前模型能力下，什么是用户的 golden path。
- 知道哪些模型弱点应该用 harness 补，哪些应该等待模型能力提升。
- 用少量高质量 [[Evals]] 定义成功标准。
- 找到少数能准确描述模型/产品质量的高品味用户。
- 在高速发布中决定哪些不完美可以先发，哪些会阻断主 use case。
- 在工具越来越强时，避免沉迷 setup，把精力放在真正产出。

## 与工程背景的关系

工程背景仍有用，因为它帮助判断成本。如果某功能一小时能做，少辩论直接做；如果很难，产品品味必须把它的机会成本纳入优先级。

## 设计视角的二次印证

[[传统设计流程已死：Jenny Wen 谈 AI 时代设计]] 从设计侧印证了同一判断：当实现变便宜，设计师的价值也从"产出精美 mock"上移到"收敛方向、判断该做什么"。Jenny Wen 认为 AI 的审美 taste 会被追上，但"决定该做什么、谁来 accountable"的 judgment 仍属于人——这与本页"产品品味是优先级与路径判断而非审美词"一致。参见 [[AI原生设计]]。
