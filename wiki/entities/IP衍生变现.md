# IP衍生变现

> 把一个 IP 的价值从原载体（游戏/玩具）延伸到影视、周边、乐园、授权合作等多个载体，形成「游戏之外」的资产价值与增量营收。

## 核心内容

IP 衍生变现是话题 A「游戏如何带来情绪价值之外的资产/IP 价值」的核心方向。两个范本：

### 乐高：IP 授权 + 跨媒介矩阵（跨界标杆）

- **IP 授权「乐高宇宙」**：与星战/漫威/DC/哈利波特等合作，授权费约占售价 5%~20%。成功关键——**封闭宇宙不抢原 IP 生意**（「乐高蜘蛛侠一看就是乐高」），让互为死对头的迪士尼/索尼/华纳都愿授权。原则：野心不能太大，一切围绕核心。
- **跨媒介推广矩阵**：《乐高大电影》（全球 4.68 亿美元票房）、YouTube 动画、真人秀《LEGO Masters》——外围业务都为核心产品（积木）打辅助、路人转粉。
- 详见 [[乐高的三大商业战略（小Lin说）]]。

### 王者荣耀：自有 IP 生态化续命

- 阅文背景小说《王者时刻》、选秀综艺「无限王者团」、音乐影视、KPL 电竞——用腾讯内容生态白嫖式反哺，延缓游戏衰老。
- 详见 [[王者荣耀日赚20亿的商业秘密（海盗Talk）]]。

## 对天美的启示

- 乐高的「封闭宇宙授权」策略可迁移到天美 IP 的联动/衍生品设计——用自有风格重新包装外部 IP，做到不冲突、可共赢。
- 「跨媒介矩阵反哺核心」与王者的生态化续命同构：衍生品的首要目的不是各自盈利，而是扩大核心受众。
- 关键指标：授权分成比例、衍生内容对核心产品 DAU/付费的回流效应。
