# 基础模型

> 基础模型竞争不只是模型能力竞赛，还牵涉人才、算力、资本、产品闭环和终端场景。

## 核心内容

印奇把基础模型放进“基础模型大脑 + 物理世界终端”的战略组合里。姚顺宇材料则指出头部模型 benchmark 接近打满后，更难的是定义值得下注的问题、构建数据和 reward signal 清晰的应用场景。

## 2026-07 补充：范式转向 Agent 与世界模型

- [[杨植麟谈K2与Agentic LLM（张小珺商业访谈录）]]：2025 已完成从对话到 Agent 的范式转变；Agentic LLM 本质「多轮 + 工具」；泛化不足是最大瓶颈，需「用 L4 解决 L3」；Token efficiency > compute efficiency；模型级产品论仍成立。
- [[逐段讲解Kimi K2报告：系统工程的力量（张小珺商业访谈录）]]：K2 的价值是「系统工程大于 idea」——数据合成 + RL（Verifiable/Rubrics Reward）+ 基建工程的集成。
- [[谢赛宁7小时访谈：世界模型与AMI Labs（张小珺商业访谈录）]]：反 LLM-only，主张 [[世界模型]] 须融合视觉与具身。
