# 跨界商业案例

> 汇集游戏行业之外、但对「游戏商业化增量」有借鉴价值的商业模式案例，为跨界思维提供素材库。以下数字为 2026-07-01 联网核实（维基百科/官方财报），标注年份。

## 核心内容

话题 A 强调「从跨界领域获得灵感」。本页作为跨界案例的聚合入口，收录可迁移到游戏资产/IP/创作者经济的非游戏案例。

### 泡泡玛特（盲盒潮玩 → 抽卡/皮肤经济）

- 模式：盲盒 + 自有艺术家 IP 潮玩 + 全渠道（门店/机器人商店/线上）。
- 数字：2024 总营收约 130.4 亿元（≈18.5 亿美元，同比翻倍）；**自有 IP 占营收 76.5% > 授权 IP 16.5%**；Labubu(The Monsters) 2025 上半年收入 48.1 亿元、占比 34.7%。
- **对游戏的启发**：隐藏款=稀有皮肤/抽卡 SSR；「人为稀缺+二级市场溢价」把情绪价值资产化；**养成自有 IP 比买授权更能沉淀定价权**。

### 乐高（积木/IP → 粉丝共创 + IP 宇宙）

- **[[乐高]]**：2023 营收约 95.5 亿美元/利润约 19 亿美元/营运利润率约 26%。粉丝共创（AFOL，「120 设计师 vs 12 万志愿者」）+ IP 授权「封闭宇宙」（不抢原 IP 生意，死对头都愿合作）+ 跨媒介矩阵（《乐高大电影》全球约 4.7 亿美元票房反哺积木）。核心迁移点：生态护城河胜过专利、「野心不能太大」聚焦核心。详见 [[乐高的三大商业战略（小Lin说）]]。

### 任天堂 / 宝可梦（IP 长线运营 → 游戏是入口）

- 数字：宝可梦累计约 **1150 亿美元**，其中**周边/零售约 1036 亿≈90%**，手游约 102 亿、电影约 11.6 亿；游戏累计 4.89 亿份、卡牌超 750 亿张。
- **对游戏的启发**（最关键）：**游戏本体收入常只是 IP 价值的一小部分**，绝大部分价值来自授权周边的长尾。对天美强 IP（王者荣耀），最大增量可能在游戏之外的授权与实体化。

### 迪士尼（IP 飞轮）

- 模式：内容→乐园→衍生品→授权，同一 IP 多环节反复变现；FY2025 营收 944 亿美元、营业利润 176 亿美元。历史上乐园曾贡献约 69% 公司利润。
- **对游戏的启发**：单一游戏 IP 应设计「飞轮」而非孤立产品线，脱离单一玩法生命周期。

### 平台分发经济（抽成 + 创作者分成 + 订阅）

- App Store 30%（小企业/满 12 月订阅降 15%）；Steam 阶梯抽成 30%→25%→20%；Roblox DevEx（2020 约 34.5 万开发者、合计约 2.5 亿美元）；Fortnite UEFN（首年向 2 万+ 创作者付约 3.2 亿美元）；Game Pass（2025 约 3500 万订阅，获客工具定位）。
- **对游戏的启发**：分成设计是增长杠杆（越大越便宜留住头部 CP）；UGC 创作者经济规模化扩内容与留存；订阅制换 LTV 与生态锁定。见 [[创作者经济]]。

## 对天美的意义

跨界案例的价值不在照搬，而在提炼可迁移的底层逻辑（护城河来源、IP 复用方式、创作者生态、资产保值机制），再回到游戏语境重新设计。综合应用见 [[天美两话题综合报告：商业化增量与游戏AI布局]]。
