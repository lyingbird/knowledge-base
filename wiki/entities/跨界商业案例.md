# 跨界商业案例

> 汇集游戏行业之外、但对「游戏商业化增量」有借鉴价值的商业模式案例，为跨界思维提供素材库。

## 核心内容

话题 A 强调「从跨界领域获得灵感」。本页作为跨界案例的聚合入口，收录可迁移到游戏资产/IP/创作者经济的非游戏案例。

### 已收录

- **[[乐高]]**（玩具/IP）：粉丝共创 + IP 授权封闭宇宙 + 跨媒介矩阵。核心迁移点——生态护城河胜过专利，「野心不能太大」聚焦核心产品。详见 [[乐高的三大商业战略（小Lin说）]]。

### 待补充方向（候选素材已在检索池，尚未入库）

- 泡泡玛特 / 盲盒潮玩：稀缺性 + 情绪价值 + 二级市场。
- 迪士尼 / 环球：乐园 + IP 授权 + 内容飞轮。
- 任天堂 / 宝可梦：IP 长线运营与跨媒介帝国。
- 平台经济 / 网络效应：分发抽成、订阅制（Game Pass）。

## 对天美的意义

跨界案例的价值不在照搬，而在提炼可迁移的底层逻辑（护城河来源、IP 复用方式、创作者生态、资产保值机制），再回到游戏语境重新设计。
