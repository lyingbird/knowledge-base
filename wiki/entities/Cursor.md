# Cursor

> AI 原生代码编辑器，本库中作为 [[Claude Code]] 之外的另一个 AI 编码工具样本，反复作为「AI 改变研发操作模型」的具体载体出现。

## 核心内容

Cursor 在多个素材里被当作 AI 编码工具的代表：[[麦肯锡：AI 时代，旧的敏捷开发方式正在拖累个人效率]] 用它说明个人任务提速已经发生，但组织若不改 [[后敏捷操作模型]] 就只能小幅获益；[[Karpathy编码原则与Claude-Code-Skills]] 把它和 Claude Code 一起列为 [[LLM编码原则]] 的落地载体（支持 `.cursor/rules/`）；[[Manus决定出售前最后的访谈：啊，这奇幻的2025年漂流啊…]] 在 AI 产品创业语境里提及它。

它和 [[Claude Code]] 是同一类「AI 原生编辑器/agent」，都把 [[AI原生工作流]]、[[Spec-driven development]] 这套理念产品化——价值不止补全代码，而是改变研发的协作单元和质量门槛（见 [[AI研发提效]]）。
