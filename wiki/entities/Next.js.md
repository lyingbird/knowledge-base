# Next.js

> 基于 React 的全栈 Web 框架，是独立开发者快速搭建 SaaS 的主流技术栈之一，常与 [[Node.js]]、[[Vercel]]、[[Stripe]] 组合。

## 核心内容

在 [[我克隆了3个成功App，现在月入3.5万美元]] 中，[[Samuel Rondot]] 的全部应用（[[UseArtemis]]、[[StoryShort.ai]]、[[Capacity.so]]）都用 [[Next.js]] + [[Node.js]] 写代码，并推荐自学者直接学这类「现代技术」。配套部署用 [[Vercel]]（Next.js 的官方托管平台），收款用 [[Stripe]]。

这套组合的吸引力在于：前后端一体、部署一键化、适合一个人维护——直接服务 [[克隆并改进1%]] 的「简单易维护」原则与两周 MVP 节奏。
