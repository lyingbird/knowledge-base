# AI 视频理解知识库（使用说明）

这是一个按 `llm-wiki` 方法改造后的个人知识库：目标不是保存零散笔记，而是把视频、访谈、案例和判断持续沉淀成互相链接的知识网络。

方法论参考 Karpathy 的 LLM Wiki：LLM 不只是检索原始资料，而是把资料读入后持续维护一个结构化 wiki。知识被编译一次，然后随着新素材和新问题持续更新。

## 从哪里开始

- 第一次来：从 [[首页]] 进入，那里有四张按问题组织的地图
- 全量清单：[[总索引]]
- 研究方向：[[06-手册/研究目的|研究目的]]
- 知识库总览：[[02-知识库/知识库总览|知识库总览]]
- 离线交互式图谱：`02-知识库/知识图谱/知识图谱.html`
- 待核验事实：[[03-核验/待核验事实]]

## 新的知识层

- `02-知识库/素材/`：每份素材一页摘要，保留来源、核心观点、待核验点。
- `02-知识库/概念/`：可复用概念、人物、组织、工具，例如 [[AI原生公司]]、[[企业上下文]]、[[智能密度]]。
- `02-知识库/主题/`：跨素材主题，例如 [[AI原生组织]]、[[企业AI产品案例]]、[[AI游戏与虚拟世界]]。
- `02-知识库/综合/`：跨素材综合报告、阶段性结论。
- `02-知识库/对比/`：对比分析。
- `02-知识库/知识图谱/知识图谱.html`：离线交互式知识图谱，双击即可在浏览器中探索。

## 四层架构

1. `00-入口/` 是导航层。只放首页和四张 MOC，不放规范。
2. `01-原始素材/` 是原始素材层。历史视频笔记已复制到 `01-原始素材/视频笔记/`，作为不可变素材副本。
3. `02-知识库/` 是 LLM 维护层。这里的页面会被持续更新、互相链接、合并矛盾和沉淀综合。
4. `06-手册/` 是规范手册层。它规定 LLM 后续如何 ingest、query、lint 和更新图谱。

## 历史内容

原有的 Obsidian vault 内容仍然保留，不再新增：

- `04-历史主题/`：旧主题页
- `01-原始素材/视频笔记/`：历史视频学习笔记，速查见 [[01-原始素材/视频笔记/视频索引|视频索引]]
- `03-核验/`：待核验事实

这些内容不会删除。新的 `02-知识库/` 层会逐步把它们整理成可查询、可链接、可综合的结构。

## 后续怎么添加素材

1. 把原文、转写或链接放进 `01-原始素材/` 对应目录，或直接提供给 AI。
2. 在 `02-知识库/素材/` 创建素材摘要。
3. 抽取实体和主题，更新 `02-知识库/概念/` 与 `02-知识库/主题/`。
4. 检查是否修正或挑战已有页面中的判断。
5. 更新 `总索引.md` 与 `操作日志.md`。
6. 有阶段性洞见时，写入 `02-知识库/综合/`。
7. 需要时重新生成 `02-知识库/知识图谱/知识图谱.html`。

维护规则详见 [[06-手册/知识库规范|知识库规范]]。
