这个人喜欢穿着短裤，整天窝在沙发上写代码，没人管他，也没有团队要他管。但是他却仅凭一人之力开发了七十多个项目，运营十几个一人公司，每月进账二十万美金。这个人就是传奇独立开发者 Peter Lewis。你可能会想，是不是他运气太好了？但真相是，他做过七十多个项目，百分之九十五都失败了，成功率只有可怜的百分之五。有趣的是，类似幸运者正在变多。比如一个用 AI 生成 Excel 工具的小工具，年入五十万；一个 AI 做趋势分析的网站，年入二十万。还有个像四三九九小游戏一样的翻车业务，居然也能年入十万以上，都是一个人的作品，没有团队，没有融资。据统计到二零二四年，全球已经有几百万的独立开发者。后头就是一个 AI 大航海时代，OpenAI 的 CEO Altman 也预言，很快世界上第一家一人独角兽公司就会诞生。这一切或许是因为 AI 开发工具的持续进化，重启了创业方式。一开始的 AI 编程呢，只能在聊天窗口一问一答，还需要把 AI 生成的代码复制粘贴到编程工具中。紧接着，Code Pilot 这类 AI 编程工具出现了，开始能补全和改写部分代码，但它的角色呢依然是辅助，而不是终端。现在进入了智能体时代，AI 不再能一步步指令，而是要从协助转变为主动。我们用一个案例来体验这个变化吧。比如这个专注于做图片背景移除的网站，功能简单，页面也不复杂，但它做到了年收入三千两百万美元。如果我们利用基于智能体的 AI 编程工具，怎么来开发这个网站呢？之前给大家演示过，怎么用腾讯云的 AI 代码助手开发一个 AI 女友。最近腾讯云 AI 代码助手升级到了新版本，还取了一个新的名字，叫做 Code Pilot。这个新版本也支持智能体模式了。那接下来呢，我就用 Code Pilot 给大家演示一下怎么开发一个年入三千两百万的网站。老规矩，打开 VS Code，进入拓展市场，搜索腾讯云代码助手 Code Pilot，点击安装。装好之后呢，可以看到比原来多了一个叫做 Craft 模式，这个就是新版本新增的智能体模式了。智能体能调用外部的 MCP 工具，先点击这个小图标，进入 MCP 市场，安装下 Playwright。这是一个能自动化控制浏览器的工具，然后再安装一个叫做 Capri 的工具，它能让智能体具备联网搜索的能力。装完这两个工具，我们的编程智能体就可以联网搜索和自动控制浏览器了。一切准备就绪，现在先别着急写代码，把自己切换到产品经理的角色，先用 Craft 模式和 Code Pilot 聊下需求。比如让它调查我们要模仿的网站具体是干什么的，要实现哪些功能，有哪些核心的技术需求，以及技术架构应该怎么设计。像这个移除图片背景核心功能，我们可以直接问它。现在有哪些方案比较成熟？分别适合什么场景？哪种方案最适合我们？讨论完毕之后，让 Code Pilot 输出一份详细的需求分析文档。需求文档确定好之后，后面的开发就简单多了。只需要在 Craft 模式里给 Code Pilot 下一个指令，根据需求文档进行开发。这个时候啊，你会看到智能体主动进行任务拆解，自动规划前后端结构，再逐一声程多个文件的代码。整个过程呢，不需要反复输入命令，也不用不停复制粘贴，智能体会根据文档自己推进开发。这就是和上一代代码助手最大的区别，从代码级辅助到真正的项目级自主开发。代码生成以后，我们可以让 Code Pilot 进行测试，智能体会调用刚刚安装好的 Playwright 工具跑测试流程。测试顺利通过，我们的产品开发环节就完成了。当然，这只是一个很粗糙的原型。一个产品想真正赚钱呢，还需要考虑运营和营销的问题。但至少从产品开发层面，我们已经证明了，现在一个人配合智能体工具，完全可以做到过去一个团队才能做到的事儿。所以呢，一人公司的涌现不是天才变多了，而是做出一个产品所需的协作成本正在被 AI 摊平，组织不再是必须，流程也不再依赖人，应用的形态也变了。以前要复杂交互才能实现的功能，现在可能只需要一个聊天窗口就够了。AI 工具的迭代已经快到以天为单位在进化，真正开始改变开发者的日常。在最近的腾讯云 AI 产业应用峰会上，代码助手 Code Pilot 正式发布，还预告了即将推出产品设计研发一体化的 AI 原生开发平台。这种 AI ID 的出现，可能会直接打破传统的岗位分工。未来程序员、产品经理、设计师之间的界限呢，或许会变得越来越模糊。软件开发团队的组织方式也可能被彻底重塑。让我们拭目以待吧。OK，那这期视频就到这儿。大家如果想体验一个人从零建构产品是什么感觉，可以试试看腾讯云代码助手 Code Pilot。这里是花子，我们下期再见。
